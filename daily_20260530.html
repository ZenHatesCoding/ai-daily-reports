Physics Is All You Need? A Case Study in Physicist-Supervised AI Development of Scientific Software

🎯 问题：如何让 AI 编程agent在科学计算软件这种缺乏真值标签的场景下正确完成任务——当无法用标准测试oracle验证时，AI生成的物理代码是否可信。
⚙️ 方法：物理学家全程监督AI coding agent（Claude Code），用oracle test suite迭代验证；记录15次干预事件并按干预层级分类；区分哪些问题agent能自主解决、哪些必须人类介入。
📦 代价：为了验证代码正确性付出了巨大的人力监督成本—— physicist 需要全程在场盯着57个sessions；agent无法自主发现需要物理直觉的错误（如量纲不一致），必须人类介入。
📊 效果：agent在12个工作日内自主解决了10/15个问题；剩余3个问题（均逃过oracle检测）需要物理学家介入；最终代码精度 ≲ 1% 对比C参考实现。
🏢 团队：Nhat-Minh Nguyen @ (机构未在文本中明确说明，从URL看是物理/AI交叉方向)

VideoMLA: Low-Rank Latent KV Cache for Minute-Scale Autoregressive Video Diffusion

🎯 问题：长视频生成的KV cache内存占用过高，当前sliding-window KV cache在长视频场景下延迟和显存成为瓶颈，需要在保持生成质量的同时大幅降低per-token KV memory。
⚙️ 方法：将Multi-Head Latent Attention（MLA）引入视频扩散模型：用共享低秩content latent替代per-head keys/values，并引入decoupled 3D-RoPEpositional key；per-token KV memory降低92.7%。
📦 代价：MLA的低秩假设在语言模型中基于spectral assumption，但视频注意力不是低秩的——论文需要额外验证为什么MLA在视频扩散中仍work，即做了额外理论分析来弥补这个假设不成立的问题。
📊 效果：per-token KV memory降低92.7%；视频生成质量持平甚至更好。
🏢 团队：Hidir Yesiltepe @ Virginia Tech

LLMSurgeon: Diagnosing Data Mixture of Large Language Models

🎯 问题：大模型预训练数据配比不透明（数据mixture是模型的"digital DNA"），外界无法审计模型训练数据的来源和比例。
⚙️ 方法：将数据混合诊断（DMS）建模为inverse problem under label-shift assumption；提出LLMSurgeon框架，估计calibrated soft confusion matrix并求解constrained inverse problem；提出LLMScan首个DMS benchmark。
📦 代价：方法依赖label-shift假设（即domain比例变化但domain内部语言模式不变），对于预训练数据有大量domain混合的模型，这个假设可能不成立，导致估计有偏。
📊 效果：LLMScan benchmark上LLMSurgeon显著优于强baseline；具体数字需要读取完整论文确认。
🏢 团队：Yaxin Luo @ MBZUAI（VILA Lab）

SchGen: PCB Schematic Generation with Semantic-Grounded Code Representations

🎯 问题：PCB原理图设计仍然是高度人工和专业的工作，当前生成式AI无法可靠地从自然语言生成可编辑的PCB原理图——因为缺少适合LLM的表示方法和大数据集。
⚙️ 方法：提出semantically grounded code representation：将原理图编辑原语编码为相对位置和基于引脚名的布线；将几何驱动问题转化为语义匹配问题；构建大规模原理图数据集并微调LLM。
📦 代价：需要构建大规模PCB原理图数据集（工程量大），且依赖agentic sketch和schematic-to-code转换pipeline来获取训练数据。
📊 效果：SchGen为首个能够从自然语言请求生成可编辑PCB原理图的LLM；文本中有具体指标，需对照原文。
🏢 团队：Qinpei Luo @ UCSD
