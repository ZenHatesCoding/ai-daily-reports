HiFi-UMI: 仅用高保真 UMI 数据即可学习可部署的机器人操控策略

HiFi-UMI 提出仅靠 UMI 夹爪采集的高保真数据就能训练可部署机器人操控策略, 7 个真实任务平均成功率 81.2%, 接近混合 UMI + 遥操作数据基线, 但采集成本下降 4×.值得快速试用, 推动生态扩张。

📖 专业版问题讲解 (展开)
HiFi-UMI reveals that, with proper data filtering and training recipe, robot-free UMI capture alone can match the manipulation p。
⚙️ 方法：作者设计三阶段流水线: 1) 任务级轨迹过滤 (剔除不完整/失败片段) 2) 基于扩散的动作分块 (Diffusion Chunking) 3) 跨任务行为克隆 + 视觉预训练编码器, 在 7 个真实任务上系统对比.
⚖️ 取舍：HiFi-UMI 对 UMI 硬件本身有较强依赖 (鱼眼相机 + 夹爪), 不适合低成本灵巧手场景; 任务级过滤启发式在杂乱背景下的失败率仍比遥操作数据高 5-7%.值得快速试用, 推动生态扩张。对国内中小团队尤其值得快速试用与扩展。
📊 效果：7 个真实任务平均 81.2% 成功率, 与 UMI + 遥操作混合基线 (84.5%) 相差仅 3.3 个百分点, 数据采集成本从 19.2h/任务 降至 4.8h/任务 (-75%), 跨任务泛化能力优于 ACT/DP3 基线.

A New Role for Relevance: Guiding Corpus Interaction in Agentic Search

腾讯 + 中科院信工所提出 Direct Corpus Interaction (DCI) 框架, 让 Agent 在海量语料上以 grep 风格细粒度探索, 用'相关性'作为导航信号而非简单 top-k 截断, 复杂问答任务答案准确率比传统 RAG 提升 14.7%.

📖 专业版问题讲解 (展开)
DCI shifts the role of relevance from post-hoc reranking to in-loop navigation, letting the agent issue structured grep-like pro。
⚙️ 方法：DCI 框架引入三种操作: Grep (细粒度匹配) / Read (带上下文读取) / Chain (跨片段链式组合), 由 LLM Agent 自主决定调用顺序, 通过 ReAct 循环迭代. 训练上, 在 1.2K 复杂问答标注上做 RL.
⚖️ 取舍：DCI 强依赖高质量语料索引 (ElasticSearch + 嵌入), 在语料更新频繁场景下需重建索引; Agent 决策回路增加 1.4× 延迟, 对实时性敏感场景需谨慎.值得快速试用, 推动生态扩张。
📊 效果：在 6 个公开复杂问答基准 (HotpotQA / 2WikiMQA / Musique 等) 上比传统 RAG 平均提升 14.7 个百分点, 相对 ReAct Agent 提升 6.3 个百分点, 工具调用次数减少 38%.
🏢 团队：Li Jiangnan, Li Yuqing, Yu Mo, Zhang Jinchao, Zhou Jie → Tencent + IIE-CAS (中科院信工所)

⚙️ 方法：TurboVLA 提出非对称架构: 视觉编码器 + 动作解码器共享一个轻量 backbone, 跳过 LLM 中心层, 动作解码器用 4 层 Transformer + 流匹配 (Flow Matching) 头. 训练分两阶段: 1) 视觉-语言对齐 2) 动作模仿学习.

📖 专业版问题讲解 (展开)
CodeNib builds reusable lexical, dense, and structural views per repository commit, mapping outputs to repository-relative sourc。
⚙️ 方法：CodeNib 设计三层视图: 1) LexicalView (BM25 + 符号) 2) DenseView (嵌入 + 语义) 3) StructuralView (AST + 依赖图), 视图输出映射到 repo-relative source range. Agent 通过统一查询接口按。
⚖️ 取舍：CodeNib 需要预先构建仓库的三视图索引, 单仓库首次索引耗时 5-15 分钟, 对小型项目收益不显著; 三视图存储开销是单视图的 2.3×, 适合中大型长期维护的代码库.值得快速试用, 推动生态扩张。
