Recursive Agent Harnesses

生产级编码 agent 要处理百万到四百万 token 的长上下文任务，但单次模型调用很难吃下这么大的工作负载；现有子代理方案缺少一个统一的命名和设计框架，业界难以横向比较与复用。

⚙️ 方法：提出 Recursive Agent Harness (RAH)：父 agent 写出一段可执行脚本，按子任务粒度并行拉起带文件系统、代码执行、规划工具的子 agent harness，小子任务则直接用结构化函数调用。优势是 harness 级递归（不只是模型调用递归），并行度与上下文分片更细。
⚖️ 取舍：把"并行拉起子 harness"作为默认单元，代价是父 agent 编排复杂度升高、脚本调试链路变长，错误定位和小任务同步开销被放大；模型选择也受限于能稳定生成可执行脚本的强 backbone。
📊 效果：在 Oolong-Synthetic（199 条，13 个上下文长度桶，最高 4M token）上，固定 GPT-5 backbone 时，RAH 把 Codex 编码 agent 基线从 71.75% 拉到 81.36%；换更强的 Claude Sonnet 4.5 同样设计可到 89.77%。
🏢 团队：Anthropic 应用研究团队；一作 Elias Lumer，合作者 Sahil Sen、Kevin Paul、Vamse Kumar Subbiah，对应其 dynamic workflows 产线方向。

Influcoder: Distilling Decoders' Gradient Influence Rankings into an Encoder for Data Attribution

数据归因（Data Attribution）用影响函数能定位训练样本对模型行为的因果贡献，但计算和存储代价随数据规模爆炸，工业级 LLM 训练语料上几乎跑不动。

⚙️ 方法：Influcoder 先用 decoder 跑全量梯度影响排序得到"教师"影响分数，再把样本级影响排名蒸馏进一个轻量 encoder；查询时只跑 encoder 一次前向即可估影响，优势是推理开销和数据存储压到极小。
⚖️ 取舍：把影响估计从"重做梯度"压成"encoder 单次前向"，代价是排序精度被蒸馏损失吃掉，跨模型族和跨任务泛化能力有限，训练/查询分布漂移时影响排名会偏。
📊 效果：在数据归因任务上 Influcoder 速度比传统影响函数高数个量级且显存占用大幅下降，同时对毒性样本溯源等用例的影响排序与原方法相关性接近，仍能定位到引发负面行为的关键样本。
🏢 团队：法国 CRIL/Université de Lille/CNRS 团队；一作 Dimitri Kachler，通讯 Damien Sileo、Pascal Denis，属 CRIL 影响力函数与数据归因方向。

ArogyaSutra: A Multi-Agent Framework for Multimodal Medical Reasoning in Indic Languages

英语中心的多模态大模型在医疗这类专业场景表现一般，到了印度农村的多语种、多模态问诊场景就基本失灵，母语患者很难获得可靠的 AI 辅助。

⚙️ 方法：ArogyaSutra 采用 actor-critic 多智能体框架，串起工具调用与双重记忆机制做步进式、可反思的医疗推理；配套 ArogyaBodha 数据集（8 个异构源、31 个身体系统、6 种影像模态、21 个临床域、含 7 种印度语言+英语）。优势是同时覆盖多语种和医学多模态的端到端推理。
⚖️ 取舍：把多语种 + 多模态 + actor-critic + 双重记忆 + 工具调用同时堆上去，代价是系统耦合度高、单条问诊延迟与 token 消耗明显高于单模型方案，临床安全护栏和评测标准也尚未在该框架上充分建立。
📊 效果：在 7 种印度语言 + 英语的医疗多模态问答基准上，ArogyaSutra 相对英文中心 MLLM 全面提升准确率；消融实验显示 actor-critic、双重记忆、工具调用各组件均有独立贡献。
🏢 团队：印度 IIT Patna 自然语言处理实验室；一作 Tanmoy Kanti Halder，通讯 Sriparna Saha，合作者 Akash Ghosh、Subhadip Baidya、Arijit Roy。

Multi-Agent Reinforcement Learning from Delayed Marketplace Feedback for Objective-Weight Adaptation in Three-Sided Dispatch

三方外卖派单需要在顾客送达质量、骑手利用率、商家拥堵之间持续权衡，但反馈信号延迟、噪声大、互相耦合，传统监督学习无法在线自适应这些运营目标。

⚙️ 方法：在 DoorDash 已部署的派单系统里保留组合优化器不动，叠加一个门店级多智能体策略：它从离线日志学到一组"派发乘子"去微调优化器的质量-效率权衡点，并用共享价值函数 + Double Q + 保守正则化抑制分布外过估。优势是不破坏生产可行性约束就能在线调整目标权重。
⚖️ 取舍：把学习范围压缩成"在现有派发优化器上加乘子"，换来了生产安全，却也把策略表达力锁在离散乘子这一薄层；延迟反馈+多 agent 价值共享在门店分布大幅漂移时仍有 OOD 风险。
📊 效果：在 DoorDash 生产环境的 switchback 实验中，离线训练的策略在保证面向顾客的送达质量不退化的同时，提高了拼单率并压低骑手侧时间成本，验证了用世界反馈安全在线适配决策策略的可行路径。
🏢 团队：DoorDash 派单/运筹团队；一作 Haochen Wu，合作者 Yi Hou、Shiguang Xie，对应 ICML 2026 RLxF workshop 接收论文。

Beyond the Commitment Boundary: Probing Epiphenomenal Chain-of-Thought in Large Reasoning Models

推理模型生成的长 chain-of-thought 中，真正决定答案的往往只是一两个关键步，但模型仍然继续"写"，既烧 token，也让人无法判断哪些步骤是因果必要、哪些只是表演。

⚙️ 方法：用"早退"衡量每一步对最终答案的因果重要性，定位到一个陡峭的 commitment boundary（承诺边界），过界后 CoT 变成不影响答案概率的 epiphenomenal 副现象；并用 attention probe 从中间隐状态线性解码出"已定型"信号，据此在该边界早退。优势是不改训练就能砍掉最多 ~55% 的 CoT 长度。
⚖️ 取舍：用 attention probe 做边界检测换取大幅省 token，代价是这套"承诺边界"只对被探查的模型族和任务分布成立，跨域泛化与早退阈值需要重新校准，而且 epiphenomenal 步骤对人类可读解释仍可能有用。
📊 效果：在多个大推理模型和任务上，承诺边界后的步骤基本不改变答案概率；用 attention probe 触发早退后，CoT 长度平均最多压缩 55%，对最终性能几乎无影响。
🏢 团队：意大利 University of Trieste / Groningen / Milano-Bicocca 合作团队；一作 Daniel Scalena，通讯 Gabriele Sarti、Luca Bortolussi、Elisabetta Fersini、Malvina Nissim，跨校 NLP 与可解释 AI 实验室。
