Locally Coherent, Globally Incoherent: Bounding Compositional Incoherence in Multi-Component LLM Agents

🎯 问题：多组件LLM智能体各组件仅看到联合问题的一部分，组合时即使局部相干，整体也可能违反基本概率公理
⚙️ 方法：提出组合残差ε*（组合预测到联合相干多面体的L2距离），产品结构二分法刻画何时局部相干足够；分层Boyle-Dykstra投影确定性修复组合；anytime-valid e-process实现序贯相干监控
📦 代价：只能在事后检测偏差但无法预防；修复过程需要额外计算开销（分层投影）；对于本身已是相干的组件该方法增加无效开销
📊 效果：1876个集成团中33-94% ε*>0；比例分配规则下每投注+0.115 nats后悔（相干投注者自身修复时降至+0.006 nats）；三种LLM端缓解策略（检索、分区感知提示、聚合器LLM）均失败或退化
🏢 团队：Anany Kotawala @ 牛津大学

Unlocking the Working Memory of Large Language Models for Latent Reasoning

🎯 问题：测试时计算扩展将推理与自回归生成耦合，混淆内部计算与外部通信；生成式推理步骤需要大量token且无法在单次前向传播中完成
⚙️ 方法：将自回归推理步骤替换为「记忆块」——固定特殊token序列，在单次前向传播中处理，实现计算高效的潜在推理；两阶段课程：先预测显式推理步骤grounding，再迭代细化最终答案
📦 代价：需要专门训练阶段适应记忆块机制；记忆块大小固定，可能不适合超长推理链；固定token序列的表示能力可能不如生成式步骤灵活
📊 效果：跨不同家族和规模语言模型，RiM匹配或超越现有潜在推理方法，且避免了推理步骤的自回归生成
🏢 团队：Lukas Aichberger @ 清华大学（推测）

Accelerating Constrained Decoding with Token Space Compression

🎯 问题：CFG约束解码引擎每步验证开销是前向传播的4倍（7B模型），复杂语法下验证成本指数增长
⚙️ 方法：通过合并语法等价token和消除冗余非终结符，同时压缩token词汇表和语法；将验证开销降低85%同时保持输出质量
📦 代价：只适用于有CFG约束的结构化输出（JSON、代码等）；对自由文本生成无加速效果；压缩质量依赖语法设计质量
📊 效果：验证成本降低85%，同时保持输出质量；延迟降低达两个数量级；配合SOTA语法引擎总约束生成时间提速达7.5倍
🏢 团队：Michael Sullivan @ 斯坦福大学

Tiny but Trusted: Efficient Vision-Language Reasoning for Time-Series Anomaly Detection

🎯 问题：VLM应用于时序数据异常检测效果差；公开基准仅有区间标注而非自然语言解释，难以微调可解释决策
⚙️ 方法：构建VisAnomBench（含高质量异常解释的时序异常检测基准）；微调出参数高效VLM VisAnomReasoner
📦 代价：专用基准，泛化到其他VLM任务（如视觉问答）的能力未知；时序异常检测场景窄，模型难以迁移到通用视觉场景
📊 效果：VisAnomBench上precision提升≥21.23个百分点，F1提升≥23.87个百分点；TSB-AD-U跨基准泛化precision +9.57，F1 +13.39
🏢 团队：Xiaona Zhou @ 某研究机构

Reasoning with Sampling: Cutting at Decision Points

🎯 问题：均匀切点重采样倾向于重写局部细节而非关键决策点，采样效率低；RL训练前沿推理模型成本高且需要大量算力
⚙️ 方法：Entropy-Cut Metropolis-Hastings：用下一token熵识别关键决策点，从这些位置重采样；理论证明混合时间与决策数量而非token数量成正比
📦 代价：需要准确估计token熵分布，熵估计不准确时性能下降；对极短推理链（few-shot场景）可能无决策点可切；实现复杂度高于均匀切点
📊 效果：MATH500、HumanEval、GPQA Diamond、AIME26一致超越基线和RL训练模型
🏢 团队：Felix Zhou @ 加州大学伯克利分校
