Physics Is All You Need? A Case Study in Physicist-Supervised AI Development of Scientific Software

🎯 问题：AI智能体在科学软件开发中的可信度及人类监督的作用边界
⚙️ 方法：物理学家监督AI编程智能体(Claude Code)开发可微分一阶微扰理论模块，量化监督事件并分类
📦 代价：换来可信输出，失去智能体自主提出替代架构能力；33/57次会话调整系数仍失败
📊 效果：约2100行代码，精度<1%，57次会话，15次监督事件，仅3次无法解决
🏢 团队：Nhat-Minh Nguyen @ 未提及机构

LLMSurgeon: Diagnosing Data Mixture of Large Language Models

🎯 问题：LLM预训练数据组成不透明，难以审计模型数据来源和配比
⚙️ 方法：将数据混合外科手术建模为标签迁移下的逆问题，用校准软混淆矩阵恢复隐含混合先验
📦 代价：需要训练分类器并求解约束优化，计算开销中等；只能推断域级而非细粒度混合
📊 效果：在LLMScan上高保真恢复域混合比例，需开源LLM验证协议
🏢 团队：Yaxin Luo @ MBZUAI

Unlocking the Working Memory of Large Language Models for Latent Reasoning

🎯 问题：现有推理方法将推理与自回归生成耦合，计算资源浪费在语言生成而非内部计算
⚙️ 方法：RiM：用固定特殊标记的记忆块替代自回归生成推理步骤，实现单次前向传播的潜在推理
📦 代价：需要两阶段课程训练，可能损失CoT的部分可解释性
📊 效果：在推理基准测试上匹配或超越现有潜在推理方法
🏢 团队：Lukas Aichberger @ Johannes Kepler University Linz

VideoMLA: Low-Rank Latent KV Cache for Minute-Scale Autoregressive Video Diffusion

🎯 问题：视频扩散模型per-head KV缓存内存占用高（6GB），限制长时生成和推理速度
⚙️ 方法：Multi-Head Latent Attention，用共享低秩内容向量和分离的3D-RoPE位置键替代逐头KV
📦 代价：换取92.7%的KV内存降低，同时保持与基线相当的质量
📊 效果：KV内存降低92.7%，长时视频生成最优，推理吞吐量提升1.23倍
🏢 团队：Hidir Yesiltepe @ Virginia Tech

SchGen: PCB Schematic Generation with Semantic-Grounded Code Representations

🎯 问题：PCB schematics设计依赖人工，缺乏LLM友好的表示方法和大数据集
⚙️ 方法：语义基础代码表示，将几何驱动生成转为语义驱动匹配，配合人机协作构建数据集
📦 代价：提升生成效率和控制精度，但可能牺牲设计的完全灵活性
📊 效果：在wire connectivity accuracy和functional correctness上显著优于其他方法
🏢 团队：Qinpei Luo @ UC San Diego
