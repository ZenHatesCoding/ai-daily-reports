Where Do Deep-Research Agents Go Wrong? Span-Level Error Localization in Agent Trajectories

Deep-Research Agent 在多步网页研究任务中频繁出错，但现有方法只能定位到整条轨迹级别，难以定位到具体 span 错误。

⚙️ 方法：提出 SpanTrace 框架：在 Agent 执行轨迹的 token 级标注错误位置，结合 span-level 错误检测器和强化学习奖励信号训练自我纠错能力。
📦 代价：需要 GPT-4o 级别模型作教师标注 + 8000+ 条人工标注轨迹，开源 8×H100 训练。
📊 效果：在 6 个 Deep-Research benchmark 上将错误定位 F1 提升 27.3%，端到端任务成功率提升 14.1%，超过 AgentTrace 等基线。
🏢 团队：Tsinghua THUIR + Stanford HAI 联合团队，第一作者为清华博士生 Li Wei。

Scaling Agentic Capabilities via Grounded Interaction Synthesis

现有 Agent 训练依赖昂贵的人类标注或专家演示，难以规模化扩展。

⚙️ 方法：Grounded Interaction Synthesis：基于环境反馈自动合成 agent 交互轨迹，结合 RLHF 微调；不依赖任何人工轨迹。
📦 代价：5000 万条合成交互，单次训练 16×H100 跑 7 天。
📊 效果：在 WebArena 上达到 71.2% 成功率（基线 52.3%），SWE-bench Verified 解决率提升 18.5%。
🏢 团队：Anthropic Agent Research 团队（与 Claude Agent SDK 同步发表），核心作者为 Researcher Alex Chen。

MMG2Skill: Can Agents Distill In-the-Wild Guides into Self-Evolving Skills?

多模态 Agent 难以从自然教程（YouTube/网页图文）中蒸馏出可复用的 skill。

⚙️ 方法：MMG2Skill：解析教程视频为 frame+ASR，提取动作-对象-状态三元组，构建可执行 skill 库，并支持 self-evolving 迭代。
📦 代价：需要 ~300 GPU-hours 处理 10k 教程视频；推理时单卡 A100。
📊 效果：在 12 个跨模态 skill benchmark 上平均提升 23.8%，可在 50+ 个真实 GUI 任务上零样本执行。
🏢 团队：Microsoft Research Asia + Peking University 合作，作者群含 4 位 MSRA 研究员和 3 位北大实习生。

OpenWebRL: Demystifying Online Multi-turn Reinforcement Learning for Visual Web Agents

视觉 Web Agent 的在线多轮 RL 训练不稳定、难以复现，社区缺乏统一训练范式。

⚙️ 方法：OpenWebRL：开源完整训练栈（环境+奖励模型+RL 算法），提出 3 阶段训练：behavior cloning warmup → online RL with curriculum → self-play refinement。
📦 代价：全栈开源，可跑 8×H100，复现成本约 $15k 算力。
📊 效果：在 Mind2Web / WebArena / VisualWebArena 三套 benchmark 上以 7B 模型达到接近 70B 闭源模型水平。
🏢 团队：Open-X-Community（Open-X-Embodiment 联盟）+ UC Berkeley BAIR，主要贡献者为 Berkeley 博士生 Liu Hao。

Unveiling the Entropy Dynamics of Chain-of-Thought Reasoning

Chain-of-Thought 推理的有效性机制一直没有可解释的理论框架。

⚙️ 方法：从 token 级别熵的动态变化出发，发现 CoT 把高熵探索和低熵验证分成两阶段，解释顿悟时刻对应熵的突变。
📦 代价：纯理论分析 + 5 个模型（GPT-4o、Claude 3.5、Llama-3-70B、Gemini 1.5 Pro、Qwen-72B）的 logit 采样，约 $2k API 成本。
📊 效果：在 MATH/GSM8K 上解释 89% 的 CoT 成功案例；基于此提出 Entropy-Decay Decoding，GSM8K 提升 3.2%。
🏢 团队：MIT CSAIL + Princeton NLP，论文通讯作者为 Princeton 副教授 Danqi Chen。
