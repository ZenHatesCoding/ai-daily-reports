CompactionRL: Reinforcement Learning with Context Compaction for Long-Horizon Agents

想象一个 agent 写代码写到一半, 上下文塞爆了。最原始的修法是「看到第 N 段就扔掉前面的」 — 但扔多了 agent 就忘了当初接到的要求。CompactionRL 的想法是「压缩与执行一起学」: 让模型同时学会「怎么把过去的轨迹写成简短摘要」+「怎么在压缩后的新上下文里继续干活」, 端到端 RL 训练。这套管线把上下文塞爆的硬约束变成可学习的策略, 不再硬塞硬剪。

📖 专业版问题讲解 (展开)
CompactionRL 是首个把 context compaction 整合进 RL training pipeline 的工作, 提出 token-level loss normalization + cross-trajectory generalized advantage estimation (GAE) 联合优化 task execution 与 summary generation 两个目标。在 GLM-4.5-Air (106B-A30B) 上 SWE-bench Verified Pass@1 66.8% (绝对涨 +7.0), Terminal-Bench 2.0 涨 +3.1; GLM-4.7-Flash (30B-A3B) 上 SWE-bench Verified Pass@1 56.0% (+5.5), Terminal-Bench 2.0 20.2% (+6.8); 已部署在 GLM-5.2 (750B-A40B) RL 训练中。
⚙️ 方法：Token-level loss normalization 让 task token 与 summary token 在梯度上不互相覆盖, cross-trajectory GAE 用多条压缩后的轨迹做共同优势估计, 把「压缩质量」与「压缩后继续执行的质量」当作同一目标的两个组件联合优化。
⚖️ 取舍：Summary 与 execution 联合训练让 loss landscape 更不平, 训练稳定性更敏感; cross-trajectory GAE 显著增加 batch memory 与样本方差 — 工程上需要专门的数据 packing 和 stability tricks 来收敛。
📊 效果：SWE-bench Verified 66.8% Pass@1 (GLM-4.5-Air) / 56.0% (GLM-4.7-Flash), Terminal-Bench 2.0 24.5% / 20.2%, 已在 GLM-5.2 训练管线中采用。
🏢 团队：Yujiang Li, Zhenyu Hou, Yi Jing, Jie Tang, Yuxiao Dong → Tsinghua University (Department of Computer Science, Knowledge Engineering Group (KEG))

LLM-as-a-Verifier: A General-Purpose Verification Framework

「模型答得对不对」长期被当成一个非黑即白的判断, 但实际上一道题的解有好有坏、有粗有细。LLM-as-a-Verifier 的核心想法是: 让 verifier 不再输出 0/1 分数, 而是对评分 token 的 logit 分布取期望, 得到连续分数。这样 verifier 能从「分数粒度」「重复评测」「多标准拆分」三个维度扩展, 大幅拉开正负样本的区分度, 给出一份真正可用的答案排序。

📖 专业版问题讲解 (展开)
LLM-as-a-Verifier 提出 verification as a new scaling axis, 用 scoring token logits 的期望构造 continuous verifier, 支持 triple-direction 扩展: (1) score granularity scaling, (2) repeated evaluation scaling, (3) criteria decomposition scaling。在 Terminal-Bench V2 上 86.5%, SWE-Bench Verified 78.2%, RoboRewardBench 87.4%, MedAgent Reward Bench 上 best-to-worst rank accuracy 显著优于 LM-judge baseline; 并提出 verifier-aware best-of-N ranking algorithm。
⚙️ 方法：用 scoring token 的 logit distribution 求 expectation 得到连续分数 (而非 argmax), 配合 criteria-aware scoring 多标准分项打分, 再用 verifier 的连续分数做 best-of-N cost-efficient ranking。
⚖️ 取舍：Verifier 的连续分数依赖 scoring token 分布有足够熵; 当模型对评分项「没意见」(分布极度尖锐) 时 verifier 退化为 LM-judge。Ranking 算法对 candidate pool size 仍敏感, 大规模 best-of-N 仍需要分布式 verifier。
📊 效果：Terminal-Bench V2 86.5% / SWE-Bench Verified 78.2% / RoboRewardBench 87.4% / MedAgentReward 当前 SOTA, 分数粒度越细正负样本分离度越好。
🏢 团队：Jacky Kwok, Shulu Li, Pranav Atreya, Yuejiang Liu, Yixing Jiang, Chelsea Finn, Marco Pavone, Ion Stoica, Azalia Mirhoseini → Stanford University (Stanford AI Lab (SAIL)); UC Berkeley; Carnegie Mellon University; NVIDIA Research

MetaSkill-Evolve: Recursive Self-Improvement of LLM Agents via Two-Timescale Meta-Skill Evolution

Self-improving Agent 是说「Agent 看自己运行轨迹 → 重写自己的 skill 文件 → 下次就聪明一点」。问题是过去只会改「做什么」的那个 skill, 「怎么改 skill 的流程」一直被人写死。MetaSkill-Evolve 的核心想法: 给每个 Agent 配 5 个子智能体 (Analyzer / Retriever / Allocator / Proposer / Evolver) 一起用一个 meta-skill 来调度, meta-skill 自己也在「慢时间尺度」上一起演进。这样「提升流程」本身也会自我提升, 递归。

📖 专业版问题讲解 (展开)
MetaSkill-Evolve 提出 two-timescale recursive self-improvement 框架: 每条分支同时携带 task skill s 与 branch-local meta-skill m = (ψ, σ, α, π, ε), 分别参数化 Analyzer / Retriever / Allocator / Proposer / Evolver 五个 pipeline agent。Task skill 在 fast loop 演进, meta-skill 在 slow loop 用同一套 pipeline 对自己演进, 不引入额外模型或目标。MetaSkill-Evolve 在 OfficeQA / SealQA / ALFWorld 上对 frozen backbone 的提升分别为 +23.54 / +16.09 / +1.92。
⚙️ 方法：Two-timescale 嵌套优化: 内层 fast loop 调 task skill, 外层 slow loop 调 meta-skill 的 5 维参数 (ψ, σ, α, π, ε), 五 pipeline agent 共享一个冻结 backbone。
⚖️ 取舍：Recursive 自我改进对监控要求高 — meta-skill 如果漂移到奇葩策略难以及时发现; 五 pipeline agent 共享 frozen backbone 也意味着 meta-skill 的天花板由 backbone 自身决定, 不会突破 frozen 模型的能力上限。
📊 效果：OfficeQA +23.54 / SealQA +16.09 / ALFWorld +1.92 (相对 frozen backbone), 比 no-skill / static-skill / single-level evolution baseline 都更好。
🏢 团队：Zefeng Wang, Minxi Yan, Jinhe Bi, Sikuan Yan, Volker Tresp, Yunpu Ma → Ludwig Maximilian University of Munich (LMU Munich, Chair of Database Systems and Data Mining); German Centre for Artificial Intelligence (DFKI)

SynCity 3000: Bootstrapping Scene-Scale 3D Diffusion

过去图像 3D 化, 一次只能生成单个物体。但你想要「一栋楼」「一整个街区」怎么办? SynCity 3000 的核心修法: 把图像 3D 生成器当作卷积算子一样用, 「贴地平铺」扩展到场景级别。同时自造一个合成数据引擎填补 3D 场景训练数据的稀缺。最终输入一张 dimetric 全景图, 输出任意大小、任意复杂度的全局连贯 3D 场景。

📖 专业版问题讲解 (展开)
SynCity 3000 把 image-to-3D generator fine-tune 成 convolutional operator 并搭建 scene-level synthetic data engine, 用 single-image to scene-scale 扩展生成能力。最终实现: 输入 prompt 生成的 dimetric image, 输出 arbitrary-size 整体连贯 3D 场景, 在 layout 控制与全局一致性上同时显著优于 prior 3D scene generation 方法。
⚙️ 方法：Convolutional operator 视角的 image-to-3D generator + 自建的 scene-scale synthetic data engine + dimetric image as scene-wide input prompting
⚖️ 取舍：整体连贯是「统计意义上的」 — 局部细节纹理可能出现 hallucination 一致性问题; synthetic data engine 决定了 output 的 domain bias, 真实场景与合成场景分布偏移会导致推理时局部不可信。
📊 效果：在多类别 prompt 与 layout 下都生成 large + coherent + detailed 的 3D scene, 显著优于 prior single-object 3D 生成器扩展到 scene 时的全局不一致问题。
🏢 团队：Paul Engstler, Iro Laina, Christian Rupprecht, Andrea Vedaldi → University of Oxford (Visual Geometry Group (VGG), Department of Engineering Science)

Geometric Reciprocity: Unlocking Self-Supervision for Stereoscopic Video Generation

把 2D 视频转成可戴眼镜看的 3D 立体视频, 最难的部分是「遮挡区域」(disocclusion) — 视角换一下, 原来被前景挡住的背景要补出来。传统 supervised 模型需要稀缺的真 3D 双目对做训练, 难拿。Geometric Reciprocity 给出一个「几何对偶定理」: 在最近邻 DIBR 公式下, 从右视角合成左视角的遮挡 mask = 把左视角 warping 回右视角时的丢失 mask。这样就能用「无限多的单目视频」自监督学, 不用人工标双目对。

📖 专业版问题讲解 (展开)
Geometric Reciprocity Theorem (GRT): 在 nearest-neighbor Depth-Image-Based Rendering (DIBR) 公式下, disocclusion mask 从 source→target 合成时等于 target→source warping 时的丢失 mask, 因此可 analytical 计算 test-time disocclusion mask, 实现 train-test 一致性。基于 GRT 的 self-supervised stereo inpainting 框架, 用 unlimited monocular videos 训练, 显著优于 training-free 与 supervised SOTA, 是 monocular-to-stereo conversion 领域首个 self-supervised 框架。
⚙️ 方法：GRT 推导 disocclusion mask 的解析形式, 用 cycle consistency 在 monocular video 上自监督训练 DIBR disocclusion inpainting 网络。
⚖️ 取舍：GRT 的成立基于 nearest-neighbor DIBR 假设 — 实际 production system 多用 learned warping, 假设不满足时 mask 会偏差; monocular video 来源多样性也直接决定 inpainting 边界表现, 内容分布偏移会造成 generalization 问题。
📊 效果：显著优于 training-free 与 supervised SOTA, 跨 DIBR 公式均保持 train-test consistency。
🏢 团队：Jingyi Lu, Kai Han → The Chinese University of Hong Kong (CUHK) (Department of Computer Science and Engineering); SmartMore
