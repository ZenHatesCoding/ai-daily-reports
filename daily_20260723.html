TimeLens2: Generalist Video Temporal Grounding with Multimodal LLMs

TimeLens2 把视频时序证据作为区间集合进行端到端监督与优化,提出基于合并区间支撑的 Wasserstein 奖励解决变基数与碎片化问题,2B 至 8B 全系刷新 Qwen3-VL 同尺寸 SOTA,4B/8B 击败远大于自身的开源对手。

📖 专业版问题讲解 (展开)
把视频时序证据作为区间集合处理,Wasserstein W1 奖励精确度量变基数预测,2B 即可在多个基准击败同尺寸对手并大幅超越 Qwen3-VL 主干,缩放规律清晰。
⚙️ 方法：把时间证据统一视作区间集合处理:TimeLens2-93K 用字幕提议、独立定位、跨智能体共识、语义校验与边界细化构造可靠多跨度监督,时序 Wasserstein 奖励在合并区间支撑上计算精确一维 W1 距离,辅以 IoU 奖励给出精确重叠反馈。
⚖️ 取舍：依赖多智能体共识与语义校验流水线构造 93K 标注,数据标注链路复杂、对长视频标签质量敏感;Wasserstein 奖励基于均匀分布假设,真实片段内密度不均时奖励粒度下降,需要进一步分位化处理以避免偏置。
📊 效果：在七个基准上 2B 版本全面超越同尺寸基线,4B/8B 取得 SOTA 并击败最多 397B 参数开源模型,2B/4B/8B 相对 Qwen3-VL 主干 mIoU 分别提升 14.2/13.0/18.1 点,缩放曲线稳健可复现。

EvolvingWorld: An Open-Schema Framework for Co-Evolving Role-Play Agents and World Model in Interactive Literary World

EvolvingWorld 把交互文学模拟建模为角色与世界共同演化的长程过程,用开放式 Schema 取代固定模板,Character Agent 与 LLM World Model 协同推进场景与状态,57 部书 138K 数据配合 10 维 20 指标 LLM-as-Judge 验证长程一致性显著提升。
