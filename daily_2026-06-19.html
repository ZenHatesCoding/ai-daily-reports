⚙️ 方法：首次把 rubric 作为 on-policy 自蒸馏的细粒度条件，绕过单条参考 CoT 的噪声问题

⚙️ 方法：首个端到端用扩散 LLM 做形式定理证明的框架，把生成范式从自回归里解耦
⚖️ 取舍：扩散模型的迭代去噪在推理时需要多轮 forward，证明生成端到端延迟显著高于单 pass 自回归；dLLM 的训练数据规模与质量与自回归 LLM 不在同一量级，社区可复现性受限；当前实验集中在 Lean 系语言，对 Isabelle / HOL 系的高阶逻辑体系外推尚未验证。

⚙️ 方法：首次把立场纠缠（stance entanglement）作为 MAS 决策复杂度的独立类别
⚖️ 取舍：多轮 fictitious play 推理成本随 agent 数线性增长，对 10+ 利益方的复杂博弈延迟不可忽略；均衡搜索过程对 prompt 设计敏感，立场描述偏差会让 best response 漂移到错误均衡；对自然语言博弈的可形式化部分依赖任务结构，纯定性谈判场景难直接套用。

⚙️ 方法：Turing-RL 首次以图灵测试判别度作 RL reward 训练 user simulator
⚖️ 取舍：LLM judge 自身存在偏差与奖励劫持风险，模拟器可能学会针对特定 judge 的偏门话术；图灵判别度天然倾向 "平均用户"，对极端少数派个体的可复现性未做系统验证；图灵 reward 与 ground-truth 回复似然之间可能产生张力，需要额外约束防止模拟器沦为 "判官驱动型用户"。
