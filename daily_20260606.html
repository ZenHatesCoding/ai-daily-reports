Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads

LLM agent 正在从一次性问答助手演变为长时运行的软件 actor，跨 session 持续推理、累积交互历史已是刚需。但市面 agent memory 方案形态迥异（flat retrieval / LLM 抽取 / fact store / agentic control flow），缺乏统一系统视角——写读路径开销怎么分摊、刷新与延迟怎么取舍、构造调度怎么编排全是黑盒，工程上无法规模化部署。

⚙️ 方法：首次对 agent memory 做系统级表征：四维分类法（构造/检索/生成/控制流）+ 阶段感知 profiling harness 把开销拆分到 construction / retrieval / generation 三段，再对 10 个代表系统跑两套基准定位写读路径上设计选择带来的成本迁移。
⚖️ 取舍：taxonomy 是观察性总结而非算法，不直接给出最优 memory 配方；phased profiling 在闭源 agent 后端可观测性有限，结论外推到生产黑箱 agent 时衰减明显。
📊 效果：覆盖 10 个开源/商用 agent memory 系统，量化 construction 调度、capability floor、query-volume 摊销、freshness-latency 取舍、fleet-scale 管理的成本曲线；提炼 10 条系统级工程建议。
🏢 团队：斯坦福（Stanford）/ 鲁汶大学（KU Leuven）等；Yasmine Omri、Ziyu Gan、Thierry Tambe 等（arXiv 2026-06）。

PC Layer: Polynomial Weight Preconditioning for Improving LLM Pre-Training

LLM 预训练中权重矩阵的奇异值谱常出现极端分布——少数高奇异值主导梯度流、压低低秩方向的学习速度；既有谱控制手段要么是 weight decay 这类间接正则、要么是 post-hoc 重参数化训完得换推理结构，训推无法同构。

⚙️ 方法：在每个 Linear 层前插一个 polynomial preconditioner（PC layer）重塑奇异值谱；训完 PC 可吸收回原 Linear，推理时零结构开销。Llama-1B 上 AdamW / Muon 都跑通，理论证明谱均匀有界可保证深线性网络几何收敛到全局最小。
⚖️ 取舍：PC 对权重做多项式变换，每步前向/反向多算几次低阶多项式，单步 wall-clock 略涨；阶数和频谱整形幅度需要超参搜索，不合适的阶数反过来抑制高阶谱方向的学习自由度。
📊 效果：PC layer 在 Llama-1B 预训练上对 AdamW 和 Muon 都给出稳定增益（loss 曲线更平滑、收敛步数缩短），理论证谱均匀有界对深线性网络几何收敛到全局最小充分；代码开源 https://github.com/Empath-aln/PC-layer。
🏢 团队：伊利诺伊大学香槟分校（UIUC）；Senmiao Wang、Ruoyu Sun、Alex Schwing 等（arXiv 2026-06）。

A Vision-language Framework for Comparative Reasoning in Radiology

医学影像 AI 长期停在'单图孤立读片'——一张胸片给一个结论。但真实放射科诊断依赖'跨片对比'：这次比上次好了多少？这个病灶和哪种典型最像？现有 vision-language 模型没把'跨片对比推理'做成 first-class 任务，临床可用性差。

⚙️ 方法：把对比读片形式化为 entity-aware 跨图推理：建 MedReCo-DB（690k 影像 + 160k 患者、8 机构 / 4 国 / 7 模态），把报告拆为解剖/异常/病理三类实体做监督；训出 MedReCo 检索 encoder + MedReCo-VLM 生成式对比解读，支持 reference-case 检索与时序对比两种范式。
⚖️ 取舍：实体分解依赖报告标注质量，不同医院报告模板和粒度差异大，跨中心迁移时 entity taxonomy 需要重新对齐；模型在罕见病种（训练样本稀薄）的 retrieval Recall@1 仍落后于常见病。
📊 效果：MedReCo 在 12 个内部检索 setting 上 Recall@1 全 SOTA，外部检索平均 +6.0 pp；MedReCo-VLM 在所有对比生成 eval 上最佳，胸片 longitudinal 准确率 +14.5–46.5 pp，CT +13.0–27.9 pp。
🏢 团队：上海交通大学（Shanghai Jiao Tong University）与上海人工智能实验室（Shanghai AI Lab）；Tengfei Zhang、Weidi Xie、Yanfeng Wang 等（arXiv 2026-06）。

Reinforcement Learning Elicits Contextual Learning of Unseen Language Translation

LLM 翻译极端低资源语言卡在两路：继续预训练/微调会过拟合到具体语言、零样本迁移差；塞语法书到 context 又只对个别语言有效。要让 LLM 真正'会一类从没学过的语言'，得让它习得'从 in-context 语料中调用语言学知识'这个 meta-skill，而不是死记某种语言。

⚙️ 方法：用 outcome-based RL（chrF 作 reward，PPO 策略梯度）替代 SFT，让 LLM 学会从 rich linguistic context 中抓取语言学线索。证明 surface-level 翻译 metric 即可作 RL 信号，无需复杂奖励模型。
⚖️ 取舍：chrF 是 surface-level n-gram 重叠，奖励形态简单，模型被引导到'词面像'的翻译；需句法/形态重排的语种（粘着语、声调语）fluency 提升有限；RL 训练对超参与 prompt 模板敏感，跨语族迁移时策略不稳。
📊 效果：在完全 unseen 的低资源语言上，RL 训练模型相对 in-context learning 和 SFT 都取得更高 chrF；说明 outcome-based RL 的'meta-skill 学习'能力可从数学/代码场景扩展到语言习得场景。
🏢 团队：苏黎世大学（University of Zurich）；Hanxu Hu、Rico Sennrich 等（arXiv 2026-06）。

Latent Reasoning with Normalizing Flows

LLM 显式 chain-of-thought 推理强，但每步都要 verbalize 成 token——带宽低、必须串行、KV-cache 兼容性差；现有 latent reasoning 又常牺牲掉自回归 LLM 的关键能力：原生 left-to-right 生成、概率采样、KV-cache、可微 likelihood。要么改不了推理 backbone、要么训不起来。

⚙️ 方法：NF-CoT：在 LLM backbone 内嵌一个 TARFlow 风格 normalizing flow 作 NF head；token 仍走标准 LM head，连续 thought 由 NF head 在同一因果流中生成——既保留 left-to-right 解码、KV-cache、概率采样，又给 latent thought 配 tractable likelihood，可直接对 latent reasoning 空间做 policy gradient。
⚖️ 取舍：NF head 在每个 continuous-thought 位置多算一次 normalizing flow，wall-clock 高于纯显式 CoT；NF 蒸馏的 continuous thought 来自显式 CoT teacher，质量上限被 teacher 限制，long-horizon 任务上 teacher 与 student 的 gap 会被放大。
📊 效果：在 code-generation 基准上 NF-CoT 同时超过显式 CoT 和先前 latent-reasoning 基线，pass rate 提升且 intermediate-reasoning cost 显著下降；continuous thought 的 exact likelihood 让 latent-space policy gradient 可直接优化。
🏢 团队：Apple ML Research 与伊利诺伊大学香槟分校（UIUC）；Guancheng Tu、Yizhe Zhang、Jiatao Gu 等（arXiv 2026-06）。

chopratejas/headroom

headroom 是面向 LLM 应用的上下文压缩中间件，定位于工具输出、日志、文件与 RAG 结果送入大模型前的瘦身环节。提供 Library、Proxy、MCP server 三种形态，可将 token 量压缩 60-95% 而不损失答案质量。与单纯摘要去重不同，它面向工业级长上下文流水线，能在代理、RAG、Copilot 等多跳场景显著降低推理成本与延迟。技术栈以 Python 为主，配套 MCP 协议接入，便于在 Claude、Cursor 等生态快速集成。判断：随着 LLM 应用从原型走向生产，context 预算成为关键瓶颈，token 压缩层将和缓存、路由一样成为标准中间件。

CopilotKit/CopilotKit
