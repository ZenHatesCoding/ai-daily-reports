AskChem: Claim-Centered Infrastructure for Chemistry Literature Synthesis

AskChem 把化学文献综述重构成查询结构化声明图谱：每条化学结论作为可追溯事实单元，agent 直接查询而非读论文，把跨论文证据组装加速一个数量级，等于给 AI 化学家配了一台可审计证据链的搜索引擎，是化学 LLM 基础设施级突破。

📖 专业版问题讲解 (展开)
AskChem 是面向 AI 化学 agent 的领域专用检索基础设施，将化学文献综述重构为对可追溯声明单元的查询，结合跨论文证据图谱与 API 接口，把 LLM 在化学综合任务上的可审计性与吞吐量同步提升一个数量级。
⚙️ 方法：作者提出 claim-centered 抽象，把每条化学文献结论拆成可追溯的事实单元并建立跨论文证据图谱，配合可验证证据链与 agent API 接口，让 LLM 化学 agent 像查询结构化数据库一样工作而非返回文档排名。
⚖️ 取舍：依赖合作机构提供底层结构化声明标注的高质量语料，标注链路超长且对化学领域 expert time 成本敏感；当领域扩张到非化学学科时 claim schema 需要重新设计，迁移性受限。值得快速试用, 推动生态扩张。
📊 效果：在跨 4 家研究机构的化学合成场景中，AskChem 把跨论文证据组装速度相对基线手工流程提升一个数量级，并首次实现 LLM 化学 agent 的可审计证据导出，对 FAIR 数据原则的机器可读化有直接推动。
🏢 团队：NYU + MatterStack.ai + Princeton

PhiZero: A World Model Built Around Physical Language

PhiZero 用"物理语言"把世界模型从像素黑盒拽回结构化表征：把物理规律拆成离散 token 序列，先预测物理状态再生成视觉，等于给世界模型装了一本机器可读的物理语法书，对机器人决策与具身 AI 是直接加速器。

📖 专业版问题讲解 (展开)
PhiZero 提出以 physical language 为核心的世界状态转移表征，在 5 类跨场景评测上 SSIM 提升 14 个百分点，并首次在多任务机器人规划场景实现 100 步以上连贯物理预测，远超像素直预测基线的 18 步上限。
⚙️ 方法：作者提出 physical language 一套紧凑离散化的世界状态转移表征，把视频生成的物理预测部分约束在结构化 token 空间，配合仿真物理引擎训练信号，得到兼具像素真实与物理一致性的世界模型。
⚖️ 取舍：Physical language 离散化粒度与物理精度之间存在权衡，过细的 token 表会显著增加训练成本；当前实现对软体物理与流体动力学场景尚未充分验证，扩展到非刚体物理仍需 schema 扩展。
📊 效果：PhiZero 在 5 类跨场景物理预测评测上相比像素直预测世界模型平均 SSIM 提升 14 个百分点，并在多任务机器人规划场景中首次实现 100 步以上的连贯物理预测，远超基线 18 步上限。值得快速试用, 推动生态扩张。
🏢 团队：NLPR Institute of Automation Chinese Academy of Sciences (CASIA)
