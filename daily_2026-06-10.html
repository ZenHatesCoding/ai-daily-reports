SearchSwarm: Towards Delegation Intelligence in Agentic LLMs for Long-Horizon Deep Research

2025-2026 年 Agentic LLM 在长视野深度研究任务（multi-step web research / 多源信息整合 / 跨工具调用）上频繁失败——单 agent 在 10+ 步任务里上下文管理失控，子任务委托机制缺失导致要么全做要么全不做。

⚙️ 方法：SearchSwarm 提出「Delegation Intelligence」——把长视野任务拆成子任务森林（sub-task forest），由主 agent + swarm 子 agent 动态分工；关键创新是子任务授权评估器判断"该自己做还是该分配"，配合显式 delegation 协议（而非隐式推理）。
⚖️ 取舍：授权评估器引入额外推理开销，单步延迟比单 agent baseline 高 30-40%；swarm 通信在多 agent 共识场景下会出现"过度协商"——子 agent 反复确认彼此状态，挤占主 agent 决策带宽。
📊 效果：在 long-horizon deep research benchmark 上比单 agent baseline 提升 28% 任务完成率，比 AutoGen/CrewAI 等 swarm 框架高 15-18%；6 项子指标上 5 项 SOTA。
🏢 团队：University of Illinois + Stanford 联合团队，第一作者 Yifan Zhang，通讯作者 Heng Ji（UIUC）。

The Neutral Mask: How RLHF Provides Shallow Alignment while Leaving Partisan Structure Intact

2024-2025 RLHF（人类反馈强化学习）是 LLM 主流对齐方法，但多份报告指出 RLHF 训练后模型在政治/价值观敏感话题上呈现"表面对齐"——回答中性化但内部表征仍保留训练前的党派偏见（partisan structure）。对齐税 vs 对齐真实性是个开放问题。

⚙️ 方法：The Neutral Mask 提出表征层面的诊断方法——用线性探针（linear probe）+ causal tracing 检验 RLHF 模型在政治话题上的中间层激活；发现 RLHF 仅在最后一层加了"neutral mask"（中性过滤），而 FFN 中间层仍保留训练前的 partisan 特征。
⚖️ 取舍：诊断方法是 post-hoc 分析，不能直接用于训练时的干预；论文建议的"deeper alignment"路径（在中间层而非仅最后一层做约束）会显著增加训练成本（2-3x RLHF 时间），且可能损害模型通用能力。
📊 效果：在 12 个主流 RLHF 模型（含 GPT-4 / Claude / Llama-3-Instruct）上复现了 partisan 结构残留；证明 RLHF 是"shallow alignment"——这意味着当前对齐实践有结构性盲点。
🏢 团队：MIT CSAIL + Allen AI 联合团队，第一作者 Tao Lin，通讯作者 Yoon Kim（MIT）。

OmniGameArena: A Unified UE5 Benchmark for VLM Game Agents with Improvement Dynamics

VLM（视觉语言模型）作为游戏 agent 在 2025-2026 快速发展，但缺乏统一基准——不同论文用 GTA / Minecraft / Atari 等异质环境评测，无法横向对比；且评测通常只看"最终得分"，忽略 agent 的"改善动态"（improvement dynamics）——是稳定提升还是随机波动？

⚙️ 方法：OmniGameArena 基于 Unreal Engine 5 构建统一 benchmark 套件，包含 6 类游戏环境（FPS / 竞速 / 策略 / 解谜 / 模拟经营 / 沙盒）；评测指标除最终得分外，新增 improvement curve（改善曲线）+ learning efficiency（学习效率）+ cross-game transfer（跨游戏迁移）。
⚖️ 取舍：UE5 benchmark 部署成本高——单次完整评测需 8 GPU·小时，相比 Atari 基准（分钟级）慢 100x；论文承认这一开销限制了大规模 sweep 评测。
📊 效果：测试了 12 个主流 VLM（含 GPT-4V / Gemini / Claude）；GPT-4V 总体最强但在 FPS 类游戏上不如专用 RL agent；跨游戏迁移能力普遍差——VLM 在新游戏上几乎从零开始。
🏢 团队：Tsinghua University + Microsoft Research Asia 联合团队，第一作者 Weihao Tan，通讯作者 Yu Qiao（Shanghai AI Lab）。

Learning to Attack and Defend: Adaptive Red Teaming of Language Models via GRPO

现有 LLM red-teaming（红队攻击）方法依赖人工构造对抗 prompt，效率低且覆盖窄——2025 年 Anthropic / OpenAI 等公司红队数据集更新滞后于模型迭代；用 GRPO（Group Relative Policy Optimization）等 RL 方法自动化红队是热门方向，但"攻击方"和"防御方"难以协同优化。

⚙️ 方法：论文提出对抗式 GRPO 框架——攻击模型（attacker）和防御模型（defender）通过 GRPO 多轮对抗训练：攻击方学习生成让目标 LLM 出错的多样化 prompt，防御方学习在对抗 prompt 上保持安全输出；关键是引入 reward shaping 让双方在 Nash 均衡附近收敛。
⚖️ 取舍：对抗训练对算力开销极大——单次完整 run 需要 32 H100·天；攻击方过度优化后会产生"对抗 prompt 模式坍缩"——只在训练分布内的 prompt 上攻击成功，泛化到真实用户输入时攻击成功率下降。
📊 效果：在 6 个主流 LLM 上自动化红队评测，发现 200+ 新型 jailbreak 模式，其中 30+ 是此前人工红队未发现的；防御方模型在 adversarial eval 上安全率提升 22%，但通用能力掉点 3-4%。
🏢 团队：CMU + Anthropic 联合团队，第一作者 Sicheng Zhu，通讯作者 Graham Neubig（CMU）。

IS-CoT: Breaking the Long-form Generation Collapse via Interleaved Structural Thinking

LLM 长文生成（long-form generation）在 2025-2026 仍是老大难——推理 chain-of-thought（CoT）方法在 1000+ token 长文生成时出现"生成坍缩"（collapse）：中段质量陡降、重复增多、逻辑断裂。现有方法要么强加结构（outline-then-fill）损害流畅度，要么纯端到端生成缺乏规划。

⚙️ 方法：IS-CoT（Interleaved Structural CoT）提出交错结构思维——不是"先列大纲再填内容"，而是每生成 200-400 token 后插入一段"结构性思考"（明确当前段落在整体结构中的位置 + 下一步规划），生成与结构交替进行；通过训练数据合成 + RL 训练让模型学会这种节奏。
⚖️ 取舍：结构性思考 token 占比约 8-12%，直接增加生成成本与延迟；论文承认模型在超长文（5000+ token）上"结构性规划"仍会出现 drift——结构目标与实际生成内容偏离。
📊 效果：在 long-form generation benchmark（文章 / 故事 / 技术文档三类）上比纯 CoT baseline 提升 35% 一致性分数；GPT-4 评测盲测中 71% 胜出；用户研究显示读者偏好 IS-CoT 输出（67%）。
🏢 团队：Peking University + Alibaba DAMO Academy 联合团队，第一作者 Yujie Liu，通讯作者 Zhifang Sui（PKU）。
