Scaling the Horizon: 35B MoE Agent Agents-A1 跑出万亿参数性能

想象你只请了一个 35B 参数的「小经理」(MoE 模型) 去干活, 但他手下管的工具和数据流程特别长 —— 这篇论文就是想说, 哪怕模型不大, 只要「管事的范围」(agent horizon) 拉到足够大, 性能可以追平甚至超过 1 万亿参数的大模型。他们做了一个 35B 的 Mixture-of-Experts 模型 Agents-A1, 平均每次跑 45K token 的长流程任务, 在 12 个长流程 agent 评测上跟 Kimi-K2.6 / DeepSeek-V4-pro 等 1T 模型打得有来有回。

📖 专业版问题讲解 (展开)
Agents-A1 是 Shanghai AI Lab 提出的 35B MoE agentic 模型, 通过三阶段训练 (全监督微调 + 域级教师模型 + 多教师域路由 on-policy 蒸馏 + salient vocabulary 对齐) 在长流程 agent 任务上达到 SEAIL-0 56.4 / IFBench 80.6 / HiPhO 46.4 / FrontierScience-Olympiad 79.0 / MolBench-Bind 56.8, 与 1T 参数模型 Kimi-K2.6 / DeepSeek-V4-pro 持平或超越。核心论点是「agent horizon scaling」(长流程轨迹 + 异构 agent 能力扩展) 优于「parameter scaling」, 训练采用平均 45K token 的长流程轨迹 + verifier 反馈, 推理成本降低约 30 倍。
⚙️ 方法：三阶段训练: (1) 全域监督微调对齐基模型与基础 agent 行为; (2) 域级教师模型捕获每个域的专长; (3) 多教师域路由 on-policy 蒸馏 + salient vocabulary 对齐, 把六个异构域统一到一个可部署的 35B student model。平均轨迹 45K token。
⚖️ 取舍：优势: 35B 即可追平 1T 性能, 推理成本骤降; 限制: 训练阶段仍依赖大规模长流程轨迹 + 多教师蒸馏, 训练基础设施门槛高 (Shanghai AI Lab 自有集群), 中小机构难以复现; 长流程任务的 verifier 反馈依赖外部工具。
📊 效果：12 个长流程 agent 评测: SEAIL-0 56.4, IFBench 80.6, HiPhO 46.4, FrontierScience-Olympiad 79.0, MolBench-Bind 56.8, SciCode 44.3, HLE 47.6, BrowseComp-zh 75.5; 跟 Kimi-K2.6 / DeepSeek-V4-pro 1T 模型持平或超越, 推理成本降低约 30 倍。
🏢 团队： → Shanghai Artificial Intelligence Laboratory

DOPD: 双路 on-policy 蒸馏破解「特权幻觉」陷阱

学生抄老师答案抄得越像越好? 这篇论文说不一定。当老师和学生都能看到「考试答案」(privileged information) 时, 学生会学会「看答案」, 而不是「学能力」—— 这就是他们说的「privilege illusion 特权幻觉」。DOPD 用「双路蒸馏」让每个 token 根据「到底是不是真的需要看答案」来动态选老师, 既学到真能力, 也不浪费额外信号。

📖 专业版问题讲解 (展开)
DOPD (Dual On-policy Distillation) 由 NUS + MMLab CUHK + PKU + 京东探索研究院联合提出, 针对 on-policy 蒸馏中 privileged information 导致的「privilege illusion」失败模式: 学生模型把「能力差」和「信息差」混为一谈, 表面指标高但实际能力未提升。DOPD 提出 advantage-aware 双路蒸馏范式, 对每个 token 的监督信号动态选择「teacher branch」或「student self branch」, 配合 auxiliary signals 缓解特权幻觉。在 8 个 LLM + VLM benchmark 上稳定优于 Vanilla OPD, 并在 stability / robustness / continual learning / OOD 任务上验证。
⚙️ 方法：Advantage-aware 双路蒸馏: 对每个 token 动态选择「teacher 路径」或「student 自身路径」作为监督源, 配合 auxiliary signals 缓解 privilege illusion; 训练保留 on-policy 性质 (用 student 自己采样轨迹)。
⚖️ 取舍：优势: 第一个系统性解决 privilege illusion 的蒸馏方案, 双路机制可插拔; 限制: 双路蒸馏训练开销是单 teacher 的约 1.5-2 倍; 对 privileged information 的定义依赖任务域, 跨域泛化需要重新校准; 部署时仍需保留 teacher 模型 (或蒸馏到更强 student)。
📊 效果：8 个 LLM + VLM benchmark 一致优于 Vanilla OPD; stability / robustness / continual learning / OOD 任务上均验证优越性; 在 8× NVIDIA H200 141GB GPU 上完成全部实验。
🏢 团队： → NUS + MMLab CUHK + PKU + Explore Academy, JD (京东探索研究院)

BlockPilot: 让扩散式投机解码学会「按样本选块大小」

想象你在做「猜词游戏」: 一个小模型先猜 5 个词, 大模型一次性验证 5 个词对不对。这就是「投机解码」, 让推理快几倍。但作者发现「一次猜几个」这个数不能写死, 不同的输入该用不同的块大小 —— 他们做了 BlockPilot, 每次推理时根据 prompt 的特征动态选最优块大小, 在 Qwen3-4B 上拿到 4.2 倍加速。

📖 专业版问题讲解 (展开)
BlockPilot 由阿里 AMAP 团队提出, 针对扩散式投机解码 (diffusion-based speculative decoding) 中「块大小写死」导致的次优问题: 作者通过实验发现最优块大小在不同样本间差异显著, 且呈现「聚集在训练块大小附近」的低维结构。基于此设计 sample-adaptive policy, 在 prefill 阶段后基于 prefill 表示预测最优块大小, 仅一次预测即可无缝集成到推理流程。在 Qwen3-4B + 多个 dLLM draft 模型上验证, acceptance length 5.92, 加速 4.20× (temperature=1)。
⚙️ 方法：把块大小选择建模为「轻量级 policy learning」: 在 prefill 完成后, 用一个轻量级 policy 模型从 prefill 表示中预测最优块大小, 预测一次后即可用于整段解码。
⚖️ 取舍：优势: 第一个 sample-adaptive 块大小机制, 加速效果显著 (4.2×), plug-and-play 不改推理流程; 限制: 训练 policy 模型需要收集「不同块大小对应的 acceptance rate」数据, 训练成本高; policy 模型的泛化到不同 target LLM / draft 模型需要重新校准; 推理时多一次 forward (policy 预测), 但 overhead 极小。
📊 效果：Qwen3-4B + dLLM draft: acceptance length 5.92, 4.20× 加速 (T=1); plug-and-play, 极低 overhead, 一致改进 efficiency, 跨多个 draft / target 组合验证。
🏢 团队： → AMAP, Alibaba Group (阿里高德)

GEAR: 端到端联合训练 VQ tokenizer + AR generator, 图像生成 10× 加速

现在做图像生成, 都是「两步走」: 先训一个「分词器」(VQ tokenizer) 把图转成码, 再训一个「生成器」(AR generator) 学这些码。但这两步是分开训的, 配合不好。这篇论文说「一起训」, 用「双读头」让生成器既能预测下一个码, 又能反向指导分词器。在 ImageNet 上, GEAR 比 LlamaGen-REPA 快 10 倍收敛, 还能泛化到 VQVAE / LFQ / IBQ 不同分词器。

📖 专业版问题讲解 (展开)
GEAR (Guided End-to-end AutoRegression) 由北大 + 腾讯混元联合提出, 针对传统「VQ tokenizer + AR generator」解耦训练导致 tokenizer 不知道 generator 觉得「什么容易生成」的问题。核心创新是 dual read-out 的 codebook assignment: 一路 hard one-hot 训练 AR 预测下一 token, 另一路 differentiable soft branch 携带 representation-alignment loss 反向指导 tokenizer 优化。AR 学会把 tokenizer 推向「对 AR 友好的 index distribution」, tokenizer 自身特征变得不再 DINOv2-like, AR 反过来更 DINOv2-like。ImageNet gFID 收敛加速 10× (vs LlamaGen-REPA), 跨 VQVAE / LFQ / IBQ 泛化, 推广到 text-to-image。
⚙️ 方法：VQ tokenizer + AR generator 端到端联合训练; dual read-out codebook assignment (hard one-hot 训练 AR + soft differentiable branch 反向指导 tokenizer); representation-alignment loss 让 tokenizer 朝 AR 友好的方向优化。
⚖️ 取舍：优势: 端到端联合训练打破 VQ + AR 解耦瓶颈, 10× 加速 + 跨量化器泛化; 限制: 端到端训练显存压力大 (tokenizer + generator 联合优化), 需要较大 batch; soft branch 的 representation-alignment loss 设计需要先验, 不同 backbone 需要重新调; 评估集中在 class-conditional ImageNet, 复杂场景 (高分辨率 / 文生图细节) 还需要验证。
📊 效果：ImageNet gFID 收敛加速 10× (vs LlamaGen-REPA baseline); patch-level + 空间连贯特征显著更好; 跨 VQVAE / LFQ / IBQ 量化器泛化; text-to-image 也可推广。
🏢 团队： → Peking University + Tencent Hunyuan (腾讯混元)

MemLearner: 用「学到的记忆」打破视频世界模型长时不一致

想象你玩「无限续写小说」: AI 写一段, 你给个开头, AI 接着写, 但写到第 10 段时, 角色穿的衣服颜色变了, 场景也跑偏了 —— 这就是视频世界模型的「长时不一致」问题。这篇论文做了一个 MemLearner, 让 AI 学会「自动选最相关的记忆帧」, 不用硬规则, 也不用人标, 跟图像生成模型深度耦合, 长视频里能持续保持场景一致。

📖 专业版问题讲解 (展开)
MemLearner 由香港大学 + 复旦 + 浙江大学 + 快手科技联合提出, 针对 video world model 中「缺乏 memory」导致长时不一致的问题。之前方法用 rule-based context frame retrieval 作为 memory, 在 scene occlusion / 动态物体场景下失效。MemLearner 提出 learning-based adaptive context query 方法: 用 query tokens 桥接 context 和 predicted tokens, 通过 video generation model 的反馈信号端到端学习「选什么帧做记忆」。在长时视频一致性 / 动态场景 / 物体永久性 (object permanence) 等任务上验证显著优于 rule-based baseline。
⚙️ 方法：Learning-based adaptive context query: query tokens 桥接 context frames 和 predicted tokens, 通过 video generation model 反馈信号端到端学习, 替代 rule-based retrieval。
⚖️ 取舍：优势: 第一个 learning-based video world model memory 方案, 解决了 rule-based 在动态场景下的失效; 限制: query token 设计依赖 video generation backbone, 跨模型泛化需要重新训练; 端到端训练需要长视频序列 + 大量 GPU 时; 评估集中在 world model 任务, 真实视频生成 (如文生视频) 还需要适配。
📊 效果：长时视频一致性显著优于 rule-based baseline; 在 scene occlusion / 动态物体 / object permanence 任务上验证; 跨 video generation backbone 可集成。
🏢 团队： → The University of Hong Kong (HKU) + Fudan University (复旦) + Zhejiang University (浙大) + Kuaishou Technology (快手)
