A Five-Plane Reference Architecture for Runtime Governance of Production AI Agents

企业传统安全架构只管数据在静止/传输时的边界,但生产级 AI Agent 会自主调用工具、连接器、修改业务系统,风险从'数据跨边界'转移到'单次被允许的动作序列在内部放大'。一旦 Agent 误调工具或越权串联操作,企业既无统一的运行时治理框架,也无从审计责任归属。

⚙️ 方法：提出'五平面运行时治理参考架构'(identity / context / action / tool / system-of-record 五个治理平面),把企业安全控制点从'数据边界'前移到'每一次 Agent 决策与调用'。优势:能在不重写 Agent 自身的前提下,从外部强制插入策略、审计、撤销,把所有可治理的 hook 收敛到标准化的 5 个平面。
⚖️ 取舍：五平面架构要求企业把现有 IAM / DLP / SOAR 全部重映射到 5 个治理平面上,落地改造面广;同时'运行时 hook'会显著抬高每次工具调用的延迟与链路复杂度,高 QPS Agent 场景会先撞性能墙。
📊 效果：论文给出参考实现 + 多个企业级 Agent 编排器的映射表;在三类典型攻击(repeated prompt-injection / over-privileged tool chain / silent record mutation)上相比无治理框架分别降低 73% / 68% / 81% 的可观测风险面。
🏢 团队：独立安全研究员 Krti Tallam(原 Kamiwaza.ai 安全架构负责人),arXiv 2026-06 单作者工作,定位为'企业级 Agent 治理参考标准'提案。

Which Models Are Our Models Built On? Auditing Invisible Dependencies in Modern LLMs (ModSleuth)

现代 LLM 的训练数据、过滤、judge、奖励信号都来自其他模型,形成'递归式模型依赖'——一个模型可能依赖一个上游模型,上游又依赖另一个。这些依赖散落在不同 release/artifact 中,人工无法追溯完整图谱,导致数据合规、许可证、模型血缘审计几乎不可能。

⚙️ 方法：推出 ModSleuth 自动审计工具:用静态分析 + 元数据爬取递归遍历 HuggingFace/论文/官方公告,自动重建 LLM 训练链的'依赖图',并标注许可证与数据来源风险点。优势:把'需要专家人工溯源数周'的工作压到分钟级,首次让 LLM 血缘审计可批量执行。
⚖️ 取舍：ModSleuth 的覆盖率受限于公开 artifact 完整度——任何上游模型刻意隐藏训练管线(只发权重不发数据来源),就会在图上留下'黑盒节点',审计可信度随之打折;同时递归遍历非常吃算力与存储,大模型图谱(>1k 节点)单次扫描小时级。
📊 效果：在 50 个主流开源/商用 LLM 样本中,平均追溯到 4.7 层递归依赖,发现 12 个模型存在'未声明的商业模型派生关系',其中 3 个被多个厂商在生产链路中静默使用,合规风险显著。
🏢 团队：UC Berkeley 主攻,Sanjay Adhikesaven(本科 UC Berkeley)+ Haoxiang Sun(UC Berkeley 博后)+ Sewon Min(UC Berkeley 助理教授,前 AI2),arXiv 2026-06-09。

Reroute, Don't Remove: Recoverable Visual Token Routing for Vision-Language Models

VLM 把图像投射成几百到几千个 visual token,decoder 推理时 attention 与 KV-cache 都极贵。现有'评分-丢弃'式 token 剪枝是'永久删除':删掉的 token 在更深层可能变得关键(因为跨层语义会迁移),导致模型在复杂视觉推理上掉点,不可逆。

⚙️ 方法：提出 Recoverable Visual Token Routing:不再删除被剪掉的 token,而是'路由'到 KV-cache 的次要通道,允许后续层在需要时重新激活。优势:用同样的 token 预算把'跨层不可逆信息丢失'压到接近 0,长上下文视觉问答与高分辨率 OCR 任务上保真度显著提升。
⚖️ 取舍：次要通道意味着 KV-cache 不能像纯剪枝那样砍到 1/7,而是只能砍到 1/3 左右(显存节省 50% 上下),极限压缩比不占优;同时路由调度器需要每层做一次'激活判断',decoder 整体吞吐仅加速 1.6×(传统剪枝可达 4×)。
📊 效果：在 LLaVA-1.5 / Qwen-VL / InternVL 三个 VLM 上,文本 VQA 任务保留 99% 准确率(传统剪枝 92%),长视频问答准确率反升 1.8%;POPE hallucination benchmark 几乎不掉点。
🏢 团队：阳明交大(NYCU) Yu-Lun Liu 教授组 + Google Research,Cheng-Yu Yang(阳明交大博士生)+ Shao-Yuan Lo(阳明交大博后)+ Yu-Lun Liu(阳明交大教授),ICML 2026 投稿。

APPO: Agentic Procedural Policy Optimization

Agentic RL 改进 LLM 多轮工具调用能力时,大多数算法在'tool-call 边界'或'固定工作流'这样的粗粒度上分配 credit,根本分不清'哪一步中间决策'真正影响最终结果,导致训练信号噪声大、收敛慢,Agent 在长链任务上很难稳定。

⚙️ 方法：提出 APPO,把 Agent 的执行拆成'过程策略(procedural policy)':在每个决策点显式'分支'(branch)出多个候选动作,然后用 process-level advantage estimation 给每一步单独算 credit。优势:把 credit 分配粒度从'一整轮工具调用'压到'单个中间决策',训练信号噪声比 PPO/GRPO 类低 4-5×。
⚖️ 取舍：过程策略的'分支+credit 分配'需要为每一步维护额外 rollout 与价值头,单步训练算力是 PPO 的 2.3×;在多分支场景下策略探索空间爆炸,小模型(<7B)上反而不如 GRPO 稳。
📊 效果：在 ToolBench / WebShop / ALFWorld 三个 Agent benchmark 上,APPO 相对 GRPO 平均成功率 +6.4pp,在 32B 模型上首次把长链(>20 步)Agent 任务的成功率推到 50% 以上,刷新 SOTA。
🏢 团队：新加坡 Sea AI Lab + 南洋理工大学,Wang Xucong(Sea AI 博后)+ Ma Ziyu / Wang Yong(NTU 博士生)+ Ji Yuxiang / Yang Shidong / Chen Guanhua(Sea AI 研究员),arXiv 2026-06-09。

Verifiable Environments Are LEGO Bricks: Recursive Composition for Reasoning Generalization (RACES)

用 verifiable RL 提升 LLM 推理能力时,'环境数量'是关键——但现有手动/单条构造方法只能线性扩展,环境增长撞墙,推理泛化很快饱和,模型只会刷已见过的题。

⚙️ 方法：RACES:把每个 verifiable environment 当成 LEGO 积木,用 LLM 自动把多个已验证环境的'结构、规则、reward'做递归组合,生成指数级新环境;然后在组合环境上做 RL 训练。优势:用 O(N) 个基础环境指数级扩到 O(N^k) 个组合环境,数据合成成本骤降,推理泛化能力显著提升。
⚖️ 取舍：组合环境的质量高度依赖'基础环境是否真的 orthogonal'——如果两个基础环境的 reward 信号耦合,组合出来的环境可能 reward hack,模型会走捷径刷分;递归层数 >3 时,环境复杂度已经超出人类可审计范围,可解释性骤降。
📊 效果：在 MATH / AIME / Codeforces 三类数学与编程推理 benchmark 上,组合 64 个基础环境训出的模型比手工扩到 256 个环境训的模型准确率还高 4.1pp,AIME 2025 pass@1 突破 60%。
🏢 团队：中科院软件所 + 阿里通义,Xiang Hao(中科院软件所博士生)+ Tang Qiaoyu(通义实验室)+ Yu Le(通义)+ Lu Yaojie(中科院软件所研究员)+ Han Xianpei(中科院软件所,通讯)+ He Ben(通义实验室,通讯),arXiv 2026-06-09。
