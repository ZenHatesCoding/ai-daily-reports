Multi-LCB: Extending LiveCodeBench to Multiple Programming Languages

LiveCodeBench (LCB) 是当下主流的污染感知代码评测基准，但只覆盖 Python。Multi-LCB 把 LCB 的题目镜像转换到 12 种主流编程语言（含 C++/Java/Go/Rust/Kotlin/Scala 等），同时保留 LCB 的污染控制和评测协议。在 24 个 LLM 上跑了指令与推理评测，发现 Python 普遍 overfit、跨语言存在特异性污染、多语言性能差...

⚙️ 方法：镜像转换 + 协议保持：把 LCB Python 题目结构化转换到 12 种语言，不引入新污染
⚖️ 取舍：镜像转换受限于 Python 题目的语义可移植性，强语言特性题（C++ 模板 / Rust 所有权）覆盖不全；评测分数在弱类型语言上波动大；不能完全替代真实工程场景的多语言评测。
📊 效果：24 LLM 大规模评测：发现 Python 过拟合、跨语言污染、性能差距 10-30pt · 跨语言性能不一致：同一模型 Python 与其他语言 SOTA 差距显著，单一榜单被高估
🏢 团队：Maria Ivanova, Pavel Zadorozhny, Rodion Levichev, Ivan Petrov, Pavel Adamenko, Ivan Lopatin, Alexey Kutalev, Dmitrii Babaev → GigaCode, Yandex School of Data Analysis, Applied AI Institute

S-Agent: Spatial Tool-Use Elicits Reasoning for Spatial Intelligence

把空间推理从静态、单帧 VLM 推到时序证据累积范式。S-Agent 用空间工具（depth/pose/segmentation/3D grounding）让 agent 在多视图和视频上做证据链推理，而不是孤立的帧级预测。首次在多视角/视频空间推理上系统给出工具调用 + 时序推理的 agentic paradigm，在 3D 空间问答、视频物体跟踪等任务上比单帧 VLM 高 15-25pt。

⚙️ 方法：工具调用时序推理范式：把空间推理从单帧预测重塑为多视图证据累积
⚖️ 取舍：工具调用增加推理时延（多视图问答 3-5x 调用次数），对工具依赖强的场景鲁棒；agent 工具调用策略对未见过的工具组合泛化差；纯空间任务好，但跨模态（语言-空间）推理仍弱。
📊 效果：多视图 3D 问答 + 视频物体跟踪：相对单帧 VLM 提升 15-25pt · 工具组合自动发现：agent 在多步证据链里学出空间推理策略
🏢 团队：Yalun Dai, Hao Li, Shulin Tian, Runmao Yao, Yuhao Dong, Fangzhou Hong, Zhaoxi Chen, Fangfu Liu, Baoliang Tian, Dingwen Zhang, Tao Wang, Kim-Hui Yap, Ziwei Liu → NTU (Nanyang Technological University), THU (Tsinghua University), ByteDance, NWPU (Northwestern Polytechnical University)

ENPIRE: Agentic Robot Policy Self-Improvement in the Real World

把 coding agent 的『自动算法搜索』思路搬到真实机器人策略自改进。ENPIRE 提出可重复的反馈闭环：reset scene → 执行策略 → 验证结果 → 重新搜索策略。在真实机器人灵巧操作上首次展示 agent 完全自动策略迭代（人工只负责物理重置），目标是从人工调参时代跨到自动化 robotics research 时代。

⚙️ 方法：可重复闭环：reset/execute/verify/re-search 在真实机器人上自动迭代
⚖️ 取舍：对初始策略分布高度敏感，差初始化容易陷入次优解；reset 和 verify 流程本身是工程瓶颈，新任务要重写；闭环失败时无人工兜底，硬件损耗风险高。
📊 效果：无人工算法工程：策略搜索完全由 coding agent 完成 · 物理智能自动化：从 demo-driven 跨到 research-driven 机器人开发
