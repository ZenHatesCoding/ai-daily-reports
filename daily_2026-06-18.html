STARE: Surprisal-Guided Token-Level Advantage Reweighting for Policy Entropy Stability

问题：GRPO 类可验证强化学习已成为 LLM 推理后训练的事实标准，但工程上始终被 policy 熵崩塌困扰——训练数千步后模型熵迅速跌到 0，探索枯竭，丧失长链推理能力。论文对 token 级熵动力学做一阶梯度分析，发现核心症结是 token 级信用分配错位：每 token 的熵变化可分解为轨迹级 advantage 与"下一 token 分布上的熵敏感函数"之积，从而呈现 advantage...

⚙️ 方法：对 GRPO 下的 token 级熵做一阶分析，推导出 advantage × surprisal 四象限结构与近临界性。
⚖️ 取舍：STARE 对 batch 内 surprisal 分布敏感，小 batch 场景下分位数估计不稳，需配合大批量 rollout 才能发挥优势；目标熵带本身是经验超参，不同模型/任务需重新标定；surprisal 重加权只在 GRPO 这类 advantage-based 框架下有理论支撑，迁移到 PPO / DPO 等策略优化范式未做充分验证。
📊 效果：STARE 用 batch 内部 surprisal 分位数筛熵关键 token 子集，对其 advantage 选权重加权。 · 加目标熵闭环门控，可在 1.5B–32B 三类任务上稳定训练数千步不崩。

⚙️ 方法：提出 Safety Reflection Pretraining：在 pretraining 语料规律插入自监控反思段，把安全内化为建模目标。
⚖️ 取舍：反思段的插入频率与位置是关键超参，频率过高会稀释语言建模密度，过低又丧失反射触发能力，需逐模型尺度调优；MedSafetyWorld 是受控合成环境，复杂真实世界威胁的多步骤推理攻击可能外推有限；与已有 pretraining recipe 的兼容性、是否与高质量数据存在天然权衡未做系统讨论。

User as Engram: Internalizing Per-User Memory as Local Parametric Edits

问题：个性化 LLM 助手面临一个本质矛盾——大脑把"事实记忆"放在稀疏局部的海马体 engram、把"推理技能"放在慢速共享的新皮层；现有方案要么把事实留在权重外（自然语言记忆 / 检索索引），要么用 per-user LoRA 把事实和技能混在同一份全局 ΔW 里。后者会导致写一个用户的事实污染与该事实无关的文本，且事实数随用户线性增长时全局 ΔW 不可组合。论文提出 User as Engr...

⚙️ 方法：用 Engram 模型的 hash-keyed 记忆表承载用户事实，per-user LoRA 改成"内容 / 技能"分层。
⚖️ 取舍：Engram 模型本身的训练范式并非主流，开源实现与生态兼容性受限；hash 槽位的容量受限于嵌入维度，长尾用户的事实碰撞概率随用户数上升可能放大；外科式 edit 要求事先明确"触发位—值"配对，对话式追加事实的实时性与稳健性需额外维护机制。
📊 效果：直接召回持平 per-user LoRA，间接推理精度平均高 5.6 倍，单用户占用小 33000 倍。 · Glass-box 编辑：写入触发位精确点亮，不相关位置 bit 级不变，写错层立即报错。
🏢 团队：Bojie Li → University of Catania + University of Messina (Italy)

Complementary Attention Head Pruning for Efficient Transformers

问题：Transformer 架构通过堆层堆头扩展能力，但部署到资源受限环境时，结构化剪枝普遍依赖梯度重要性排序或随机门控——这两种方式都不稳定、易结构退化、且要大量手动调 sparsity ratio。本文提出 CAHP（Complementary Attention Head Pruning）：把 head 选择重新表述为全局图论问题，用基于图聚类结合信息论距离，识别并保留一个拓扑上互补、互不...

⚙️ 方法：把 head 选择重新建模为图论问题：图聚类 + 信息论距离识别拓扑互补的 head 子集。
⚖️ 取舍：图聚类与信息论距离的计算复杂度随 head 数呈超线性关系，大模型（百亿级以上）剪枝的开销可能反而成为瓶颈；"边际性能下降曲线"依赖一个验证集，多项式度选取仍是经验性的；目前只在 encoder 类 Transformer 与分类任务上验证，decoder-only 与生成任务的可移植性未证。
📊 效果：无需预设 sparsity ratio，由边际性能下降曲线与多项式度自动决定每层保留数。 · 在 SST-5、MNLI 上跨模型规模稳定优于梯度排序与随机门控剪枝。

Seeing Before Reasoning: Decoupling Perception and Reasoning for Shortcut-Resilient Multimodal On-Policy Self-Distillation

问题：On-Policy Self-Distillation（OPSD）让模型用自己的 rollout 训练自己，固定 copy 提供 dense token 级目标，对纯文本 LLM 推理非常有效；但把这一招直接搬到多模态大模型，会引发 shortcut——特权目标其实在根据文本参考答案而非图像引导 token。论文提出 ViGOS：把流程显式拆成"先看图，再推理"——学生先写视觉描述、再推理出...

⚙️ 方法：诊断 OPSD 迁移到 MLLM 的核心失败模式：特权目标被文本参考而非图像主导引导。
⚖️ 取舍：三 teacher 框架显著增加训练时的显存与通信开销，对小规模 MLLM 不友好；视觉描述的触发条件与生成长度仍是工程超参，不同任务上需要标定；特权 reasoning teacher 仍依赖参考答案作为锚点，扩展到无参考答案的真实开放场景需要额外设计。
📊 效果：ViGOS：先写视觉描述再推理，perception / reasoning teacher 分工监督不同 prefix。 · 无效 rollout 用参考 teacher 救回输出格式，避免全流程重启。
🏢 团队：Sihan Wang, Xiyao Liu, Lianqing Liu, Zhi Han → NVIDIA

alexzhang13/rlm

alexzhang13/rlm 是 MIT CSAIL / Alex Zhang 团队开源的 Recursive Language Models (RLM) 通用推理库,定位是 'plug-and-play 的长上下文/复杂推理 inference 框架'。它把 LLM 当作可以递归调用的 'reasoning cell'——主模型对一段超大上下文(10M+ token 代码库、整本书、长对话历史)先做摘要分块,然后把子任务再丢回同一个 LLM 反复迭代,直到产出可验证的最终答案,中间每一步都可以调用外部 tool(Python REPL、grep、SQL)。底层用 vLLM/Transformers 兼容接口,支持 OpenAI/Anthropic API 模式,只用一个 Python 装饰器就能让任意长 prompt 走 RLM 路径。仓库里预置了 4 个 benchmark(HumanEval-Long、Repo-QA、PaperQA、OOXML)与基线对比,在 '1M token 代码库回答细粒度问题' 上比 vanilla GPT-5/o3-pro 准确率平均高 28-40 个百分点。

microsoft/TRELLIS

microsoft/TRELLIS 是微软研究院开源的 '结构化 3D 生成' 模型,在 Hugging Face Spaces 上以 Gradio 演示形式托管,支持从单张图像或一段文本 prompt 直接生成高质量、可带 PBR 材质的 3D mesh / Gaussian Splatting 输出。技术核心是 '统一的结构化潜空间(Structured LATent, SLAT)':把稀疏 3D 体素 + 多视图图像特征在同一个 latent 空间里对齐,既能生成几何(三角面 mesh)又能生成外观(Albedo / Roughness / Metallic),后处理内置 mesh 简化 + 纹理烘焙 + GLB 导出。Space 提供 Image-to-3D、Text-to-3D、Multi-view 三个 tab,单 A100 即可 30 秒内出资产。
