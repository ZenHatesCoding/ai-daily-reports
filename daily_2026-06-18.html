mvanhorn/last30days-skill

last30days-skill 是一个面向 Claude/AI agent 的研究型 skill,它把过去 30 天内 Reddit、X(Twitter)、YouTube、Hacker News、Polymarket 以及通用网页的内容统一拉到同一个时间窗口里做交叉验证,然后给出一份带来源链接的'接地气'摘要。技术核心是一个 recency-aware 的多源聚合流水线:每个平台都用专门的 fetcher(Bluesky/Reddit JSON API、X 搜索、YouTube transcript、HN Algolia、Polymarket CLOB),然后通过一个'近 30 天加权 + 多源互证'的合成层把噪音贴文过滤掉,只保留被多平台讨论过的话题。封装成 OpenClaw / Claude Code 可直接挂载的 skill,用户只要问'最近 30 天 X 主题在讨论什么',agent 就能在 1 次调用内返回结构化结论。

RyanCodrai/turbovec

turbovec 是一个基于 TurboQuant 的高性能向量索引库,Rust 实现核心引擎,通过 PyO3 暴露 Python 绑定,瞄准 ANNS(approximate nearest neighbor search)场景。技术核心是:用 AVX-512/NEON SIMD 指令做量化后的距离计算(INT8/二进制向量),同时把 HNSW/IVF 索引结构跑在 Rust 上,Python 侧只负责构图和查询编排,跟 faiss 相比在同召回下吞吐有数倍提升。项目还提供 drop-in 的 sklearn-like API,可以直接替换 sentence-transformers 输出的 embedding 索引,做到'pip install 就快'。
