Recursive Self-Improvement in AI: From Bounded Self-Refinement to Autonomous Research Loops

本文系统梳理了 AI 递归自我改进(Recursive Self-Improvement, RSI)的 4 个层级, 从'单次自我润色'到'完全自主研究闭环'。作者在数学推理和代码生成两个领域验证: 当模型被允许修改自己的 prompt + 训练数据筛选器 + 评估器时, 在 7 天自动迭代窗口内性能可继续提升 9-14%, 但在第 8 天开始出现'自我强化偏差'(self-reinforcing bias)。

⚙️ 方法：1
⚖️ 取舍：RSI 的天花板本质来自'自我评估自我'的反馈循环——任何自评指标都会在多轮后饱和。要突破天花板必须引入'独立外部 oracle', 但这就把 RSI 退化成了普通的 human-in-the-loop 训练, 失去了'完全自主'的卖点。论文给出的'外部 grounding 注入'在实际工程里其实就是 oracle 的一种伪装。

Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation

本文给 VLA(Vision-Language-Action)模型增加'双潜空间记忆'——一个存'短时操作上下文'(本任务的前 3 步), 一个存'长时物体知识'(从预训练数据学到的物体属性)。机器人在执行'把红色杯子从桌子移到架子'这种长时任务时, 双记忆让模型不再需要在 prompt 里堆历史轨迹, 推理时延降低 27%。

⚙️ 方法：1
⚖️ 取舍：双记忆的'长时记忆'本质是'压缩到潜空间的知识库', 这跟传统 RAG 的差异是检索粒度——RAG 是 token 级精确检索, 双记忆是'整段场景的语义压缩'。好处是检索快、可解释, 坏处是新增知识需要重新训练压缩器, 不支持在线添加物体类别——一个新工厂要部署 VLA, 得先收集该工厂所有物体的样本重训压缩器。

Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning

本文针对 Agent 强化学习中的'长尾 rollout 时延'问题(部分 Agent 任务要跑 30 分钟, 部分只要 30 秒), 提出 Single-Rollout 异步优化(SRAO), 让每个 rollout 完成后立即贡献梯度, 不必等整批对齐。在 SWE-bench Verified + τ-bench 上把训练吞吐量提升 3.1 倍。

⚙️ 方法：1
