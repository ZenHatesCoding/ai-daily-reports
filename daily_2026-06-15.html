Results from the first Anthropic Public Record

Anthropic 发布首个'Public Record'公众态度调查：2025 年 11-12 月对 51,993 名美国成年人（覆盖全部 50 州）的全国代表性调查。48% 把'治愈疾病'列为 AI 三大期待之首，64% 担心 AI 替代工作（民主党 67% / 共和党 62%），71% 支持政府介入 AI 监管，但只有 15% 信任 AI 公司自己决定发展走向——比联邦政府（20%）还低。

💡 调查里最反直觉的数字是'政府介入 71% / 信任 AI 公司 15%'——说明公众对'AI 公司自治'路线已经厌倦。Anthropic 用 Public Record + Economic Index + Interviewer 三件套在做的事，本质是把'监管合法性'外包给数据：未来无论 EU AI Act 还是美国国会立法，Anthropic 都可以指着 5.2 万人样本说'民意就是这样'。比起 OpenAI 用 EU Code of Practice 走'与监管合作'路线，Anthropic 走的是'用民调证明监管合理'，两者策略完全不同但都在抢监管话语权。

EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery

当前 LLM 科研 agent 在不少基准上已能反超人类设计的方案,但真实科研流程里,瓶颈其实在'给 agent 装一个什么样的实验室':数据、算力、工具、接口、SOP 都很零散,模型再强也只能在贫瘠沙盒里反复低水平试错,自主科研长期卡在环境工程这一关。

⚙️ 方法：提出 EurekAgent,把研究流程拆为研究计划、基线构建、实验迭代三大环境接口,并在 9 个领域把 Gemini-2.5-Pro 等 4 类模型跑成 9 套 SOTA。优势是把科研瓶颈从 agent workflow 推到 environment engineering 一侧,让'造好实验室'本身就是研究产出。
⚖️ 取舍：为把环境工程抬到一等公民,整条 pipeline 与具体领域的工具/SOP 强耦合;换到材料、生物等新领域仍要重新对接仪器接口与数据源,跨域可迁移性被领域特化压死,通用 agent workflow 的简洁性被牺牲。
📊 效果：在 9 个科研子任务上,EurekAgent 用 Gemini-2.5-Pro、Claude-Sonnet-4-5、GPT-5、O3 等 4 类模型跑出 9 套 SOTA,并开源 EurekBench 基准与可复现环境代码。
🏢 团队：清华大学（Tsinghua University, KEG 知识工程组）+ 伦敦大学学院（UCL）。一作 Amy Xin，通讯 Juanzi Li。

EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments

现有 LLM agent 评测几乎都假设世界静止:任务、工具、文档都不变。真实部署里系统升级、依赖改版、UI 翻新每时每刻都在发生,agent 一旦被旧记忆带偏就反复犯同样的错,如何衡量并提升'环境在变'下的鲁棒性,长期缺基准。

⚙️ 方法：提出 EvoArena,把环境变化建模为渐进式更新序列,横跨 command shell、software stack、system upgrade 三类,配合记忆机制与诊断协议来追踪 LLM agent 内部记忆随环境的演化轨迹。优势是把'环境变了 agent 会怎样'变成可量化、可纵向追踪的指标。
⚖️ 取舍：为拿到细粒度的记忆演化曲线,benchmark 紧绑 command shell / software stack / system upgrade 三大类环境栈;碰到新的环境类型(浏览器插件、嵌入式设备、跨云 SaaS)就要重新设计更新源与回放管线,生态多样性被评测可控性压死。
📊 效果：实验覆盖 11 个 LLM agent 框架、4 类动态场景,系统揭示了'记忆陈旧是性能下滑主因'这一普遍现象,配套开源评测、诊断协议与排行榜,为动态环境鲁棒性提供可比较基线。
🏢 团队：Salesforce AI Research + 伦敦大学学院（UCL）+ NUS + KAIST + NTU。一作 Jundong Xu，通讯 Bryan Hooi（bhooi@comp.nus.edu.sg）与 Zhiyuan Hu。

SpatialClaw: Rethinking Action Interface for Agentic Spatial Reasoning

空间推理——判断物体在哪、如何相关、如何在 3D 中运动——一直是 VLM 的硬骨头。Tool-augmented agent 想用专业感知模块补齐短板,但效果却被'怎么调这些工具'的动作接口卡死:接口粒度不对,工具再强也接不上开放式的空间问题。

⚙️ 方法：提出 SpatialClaw,重新设计面向空间推理的 action interface:把工具调用从离散动作升级为更细粒度的连续化、带几何语义的指令通道,让 VLM 能像'手'一样直接操控 3D 场景。优势是把空间推理的天花板从'会不会选工具'挪到'接口本身能不能托住几何语义'。
⚖️ 取舍：为追求几何级细粒度,新 action interface 与具体 3D 引擎/感知栈强绑定;一旦换底层渲染器或感知模块,接口契约就要重写,通用 agent 框架的即插即用被空间专属接口压死,跨引擎迁移性被牺牲。
📊 效果：在 3D 物体定位、关系推理、运动预测等多类空间基准上全面超越现有 VLM-agent 基线,同步开源新动作接口协议、训练流水线与多视角空间评测集,并发布完整复现包。
🏢 团队：NVIDIA Research + 延世大学（Yonsei University）+ KAIST + 伊利诺伊大学香槟分校（UIUC）。一作 Seokju Cho，通讯 Seungryong Kim 与 Min-Hung Chen（NVIDIA）。

Dense Supervision, Sparse Updates: On the Sparsity and Geometry of On-Policy Distillation

On-policy distillation 把 on-policy 学生轨迹与密集教师监督拼成一道新菜,后训练圈纷纷上桌,但它究竟改动了模型的哪几根骨头,业界一直说不清:学生像在'小步快跑',却没人能讲清这些步子落在参数空间的哪里、为什么收敛。

⚙️ 方法：论文系统分析 OPD,得出两个核心发现:其一,更新是 coordinate-sparse 且偏向 FFN;其二,这些稀疏更新在参数空间形成清晰的几何结构。优势是把 OPD 从'玄学配方'变成有可解释结构的现象,为后续稀疏化、对齐、压缩提供几何地图。
⚖️ 取舍：为追求对参数几何的精细刻画,分析框架强依赖 on-policy 滚动与教师可达的设定;一旦换成 off-policy 数据、非自回归学生或非密集教师监督,稀疏-几何结论就要重做,通用 post-training 工具箱的灵活性被 OPD 专属结构压死。
📊 效果：在多组语言与视觉语言模型对上验证:OPD 更新小而稀疏、集中于 FFN、且几何上高度结构化,据此可显著压缩更新量并保留性能,实证稀疏-几何假说并提出剪枝新视角。
🏢 团队：南京大学（LAMDA 组, Nanjing University）+ 字节跳动（ByteDance）。一作 Guo Yu，通讯 Han-Jia Ye（yehj@lamda.nju.edu.cn）。
arXiv:2606.13634 · 论文精读

Operads for compositional reasoning in LLMs

'把复杂问题拆成子问题再合成'是 LLM 推理里最常用的招式,但它至今没有一个严谨的数学骨架:子问题怎么拼、能不能拼、拼错会出什么,大家都凭直觉。组合推理失败怎么定位、怎么预测,长期缺一个能站住脚的理论语言。

⚙️ 方法：论文引入 operad 这一数学结构——天然刻画'多入一出'操作及其复合——提出 questions operad Q,把子问题合成形式化,并据此分析 LLM 组合推理在什么条件下崩盘。优势是把组合推理从工程经验升级为可代数验证的数学对象。
⚖️ 取舍：为拿到可复合的代数结构,问题必须能被拆成有限、良序的子问题链;面对开放式发散、需要隐式分解或多步非确定性合成的推理任务,operad 框架要先做离散化近似,直觉驱动的隐式分解那一头的灵活性被形式化压死。
📊 效果：给出 questions operad 的形式定义与多组算例,展示 operad 不变量可定位组合失败模式,为'问题分解类提示工程'提供理论支点并系统刻画失败谱。
🏢 团队：艾伦人工智能研究院（Allen Institute for AI, AI2）+ 剑桥大学（University of Cambridge）。一作 Nathaniel Bottman，通讯 Kyle Richardson（AI2）。
