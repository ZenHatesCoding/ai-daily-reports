Physics Is All You Need? A Case Study in Physicist-Supervised AI Development of Scientific Software

AI编码智能体在科学软件开发中的可靠性边界不清：模型能写代码，但何时必须由人类兜底、兜到什么粒度，未有量化证据。

⚙️ 方法：N=1案例研究：物理学家监督Claude Code（Sonnet/Opus）历时12个工作日、57个会话，构建可微分一阶微扰理论模块CLAX-PT（JAX实现），对15次监督事件按介入级别分类编码。
📦 代价：换来可信代码与可审计过程，付出的代价是：智能体被钉死在初始架构里，33/57次会话都只调系数、拒绝重选架构分支（必须物理学家注入'各向异性BAO阻尼'概念才触发重设计）；还出现过一次通过全部oracle测试的'fudge factor'——对不上任何物理量；整体是牺牲了模型自主探索空间，换来局部可信性。
📊 效果：约2100行代码，精度<1%，57次会话中33次失败于错误架构、2次由人类领域知识补位、3次无解；揭示了oracle测试之外的'解释正确性'盲区。
🏢 团队：Nhat-Minh Nguyen @ 单作者案例研究（机构未公开）

LLMSurgeon: Diagnosing Data Mixture of Large Language Models

LLM预训练数据的域级配比是模型的'数字DNA'，但厂商几乎从不披露，事后审计无门。

⚙️ 方法：把数据配比反推建模为'标签迁移下的逆问题'：先训练域分类器，再用校准的软混淆矩阵（soft confusion matrix）修正系统性的域间混淆，最后求解一个带约束的逆问题恢复隐含的混合先验。配套发布LLMScan评测套件（用开源LLM的已知配比作ground truth）。
📦 代价：换来黑盒模型的事后配比审计能力，付出的代价是：必须先预设一个领域分类法（taxonomy），配比推断精度被这个taxonomy的粒度锁死；需要至少一个'配比已知'的开源参考LLM来校准混淆矩阵，闭源模型只能相对推断；分类器的错误会沿逆问题被放大，属于域越细、误差越敏感。
📊 效果：在LLMScan上对多个开源LLM实现高保真度的域级配比恢复，协议固定后结果可复现。
🏢 团队：Yaxin Luo @ MBZUAI（穆罕默德·本·扎耶德人工智能大学）

Unlocking the Working Memory of Large Language Models for Latent Reasoning

现有CoT推理把内部计算和外部语言生成绑在一起，每次思考都要吐token，浪费算力也限制了并行性；人类用工作记忆就能内部推理。

⚙️ 方法：Reasoning in Memory (RiM)：用一串固定特殊token（memory block）替代自回归生成的推理步，单次前向就能完成潜在推理；配合两阶段课程训练——先用显式推理步grounding这些memory block，再丢掉step级监督、只迭代优化最终答案。
📦 代价：换来单次前向、低token成本的潜在推理，付出的代价是：推理过程被压成不可读的memory block序列，可解释性几乎归零（人看不到中间思考链）；且必须先经过两阶段课程训练才能见效，直接拿来用没有涌现能力，本质上是用训练复杂度换推理时计算效率。
📊 效果：在多个家族的、不同规模的LLM推理基准上，匹配或超过现有潜在推理方法，同时避免自回归生成思考token。
🏢 团队：Lukas Aichberger @ Johannes Kepler University Linz（林茨大学）

VideoMLA: Low-Rank Latent KV Cache for Minute-Scale Autoregressive Video Diffusion

长时视频扩散模型的per-head KV缓存是显存和延迟的瓶颈（典型6GB级），滑动窗口内'换哪些token进窗口、怎么编码位置'已卷到头，per-head布局本身却几乎没人动。

⚙️ 方法：首个把Multi-Head Latent Attention（MLA）搬到视频扩散的工作：用共享的低秩content latent + 共享解耦的3D-RoPE位置键，替换per-head的K/V，每token的KV内存砍92.7%。
📦 代价：换来92.7% KV内存压缩和1.23×吞吐提升，付出的代价是：把per-head的K/V压成共享低秩latent，丢掉了逐头差异化的表征粒度；论文同时承认'视频预训练注意力本来就不是低秩的'，能work的真正原因是latent瓶颈的capacity决定有效秩而非预训练谱，所以低秩latent维度成了硬性质量上限，强行压更低就会撞墙。
📊 效果：VBench上短时域与流式基线打平、长时域综合分在所有评估方法中最高，单卡B200推理吞吐提升1.23倍。
🏢 团队：Hidir Yesiltepe @ Virginia Tech（弗吉尼亚理工大学）

SchGen: PCB Schematic Generation with Semantic-Grounded Code Representations

PCB原理图设计至今纯靠专家手工，自然语言直接生成原理图基本是空白；卡点在于没有LLM友好的表示法，也没有大规模数据集。

⚙️ 方法：提出SchGen——首个NL→可编辑PCB原理图的LLM。核心是设计一套'semantically grounded code representation'：用相对摆放+基于pin名的连线编码原理图编辑原语，把几何驱动生成问题转成LLM能做的语义匹配任务；再通过'人-智能体协作pipeline'把开源硬件设计批量转成这种表示法，造出大规模训练集。
📦 代价：换来原理图生成的线连通性和功能正确性大幅领先，付出的代价是：表示法被刻意简化（相对摆放+pin名连线），一些依赖原始EDA工具精确坐标、复杂布线规则的工业级设计表达不出来；数据集来自开源硬件，存在向常见设计、向简单结构偏移的覆盖偏差；LLM产物需要再走一步到KiCad/Altium工具链的转换。
📊 效果：在线连通性准确率和功能正确性上显著优于替代表示法和更大的通用LLM。
🏢 团队：Qinpei Luo @ UC San Diego（加州大学圣地亚哥分校）
