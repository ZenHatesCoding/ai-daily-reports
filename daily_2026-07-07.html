VLA-Corrector: Lightweight Detect-and-Correct Inference for Adaptive Action Horizon

想象一下机器人要拧螺丝: VLA 模型会一次性预测未来 8 步动作然后「盲目执行」(predict-then-blindly-execute)。如果中间打滑了一下, 它不会发现, 因为它没在看。后果: 错误一步步累积, 最后把螺丝拧飞了。这篇论文的核心想法是加一个轻量「视觉监视器」(LVM), 不断对比「预测的视觉变化」和「实际看到的视觉变化」, 如果差异持续扩大就触发一个「紧急刹车 + 重新规划」(OGG) — 抛弃陈旧动作, 重新计算后续步骤。这样既保留了 VLA 一次算多步的高效, 又能在出错苗头出现时立刻纠正, 像一个有经验的工人一边操作一边盯结果。

📖 专业版问题讲解 (展开)
VLA-Corrector 在不修改 backbone 权重的前提下, 引入 Latent-space Vision Monitor (LVM) 持续比对 predicted vs actual 视觉特征演化, 通过 Online Gradient Guidance (OGG) 在检测到 persistent deviation 时触发 truncation event + corrective replanning, 实现 event-triggered adaptive action horizon。本质是用一个轻量视觉 drift detector 把静态 open-loop chunking 升级成 event-driven closed-loop, 同时保留长 horizon chunking 的 inference efficiency。
⚙️ 方法：LVM (Latent-space Vision Monitor) 持续对比 predicted 和 actual visual feature evolution, 用 Online Gradient Guidance (OGG) 在 persistent drift 时触发 corrective replanning. 整体是 plug-in 框架, 不改 backbone VLA 权重.
⚖️ 取舍：引入额外视觉比较开销 + 需要在线触发逻辑. 在完全静态场景下 overhead 没有收益.
📊 效果：在 long-horizon contact-rich 机器人操作任务上显著提升鲁棒性. 兼容多个 VLA backbone, 集成时无需重训.
🏢 团队：Yi Pan, Miao Pan, Qi Lu, Jiaming Huang, Man Zhang, Siteng Huang, Xin Li, Jie Zhang, Yongliang Shen, Xuhong Zhang, Wenqi Zhang → Zhejiang University (OmniAI Group, ZJU ACES Lab); Alibaba DAMO Academy

Embodied.cpp: A Portable Inference Runtime of Embodied AI Models on Heterogeneous Robots

现在 VLA 模型动不动就要装个几 GB 的 Python 推理栈, 在机械臂、无人机、四足狗这些「机器人端」硬件上跑起来又慢又重, 不同机器人平台还各搞一套胶水代码。论文做的事相当于给机器人 AI 做了一个「统一操作系统」 — 用 C++ 写, 分五层 (输入适配 → 序列组装 → 主干执行 → 头插件 → 部署适配), 把多速率闭环控制、batch-1 延迟优先推理、可扩展算子这些 embodied AI 的「硬要求」一次性打包。一个 runtime 跨所有异构硬件 (Jetson / GPU / 机器人专用 NPU) 和不同机器人形态, 不再每个项目重写一遍栈。

📖 专业版问题讲解 (展开)
Embodied.cpp 是一个面向 embodied AI (VLA + WAM) 的 portable C++ inference runtime, 通过 architectural analysis 提炼出共享执行路径并组织为 5 层抽象 (input adapters / sequence builders / backbone execution / head plugins / deployment adapters). 重点解决 multi-rate closed-loop execution + batch-1 latency-first fused inference + extensible operator 与 I/O, 用一个 backend abstraction 覆盖异构硬件 + 异构机器人平台.
⚙️ 方法：C++ portable runtime, 5 层架构 (input adapters → sequence builders → backbone execution → head plugins → deployment adapters), 多速率 fused inference, 延迟优先调度, 可扩展 operator 与 I/O.
⚖️ 取舍：C++ 性能优于 Python 但开发迭代慢. 5 层抽象带来灵活性的同时也增加学习成本.
📊 效果：在异构硬件 (Jetson / GPU / NPU) 和异构机器人平台统一部署 VLA + WAM 模型, 一个 backend abstraction 跨平台.
🏢 团队：Ling Xu, Chuyu Han, Borui Li, Hao Wu, Shiqi Jiang, Ting Cao, Chuanyou Li, Sheng Zhong, Shuai Wang → Southeast University; Nanjing University; Microsoft Research; Institute for AI Industry Research (AIR), Tsinghua University

Learning to Move Before Learning to Do: Task-Agnostic pretraining for VLAs

VLA 模型现在最大的瓶颈是「专家演示数据太贵」 — 给机器人录一条完整的「看到杯子 → 走到杯子前 → 抓起来」三段视频, 比请一个真人手把手教它还贵。论文提出了一个反直觉的拆解: 「学会动」 (物理动作的物理感) 和「听懂指令」其实是两件事, 不必绑在一起学。所以他们先让机器人看一大堆「乱跑乱摸」的廉价自监督视频, 用反向动力学 (Inverse Dynamics) 让它先掌握「我的手能这样动」, 然后只花一点点专家数据去对齐「听到拿杯子就去拿杯子」。SIMPLER benchmark 上只用极少标注就达到 1M 专家演示的水平, 而且在摄像头抖动时还能保持 25% 成功率 (其他 baseline 直接归零)。

📖 专业版问题讲解 (展开)
TAP (Task-Agnostic Pretraining) 提出 Decomposition Hypothesis: 物理能力 (motor priors) 和语义对齐 (language grounding) 是两个独立目标, 只有后者需要 language supervision. 方法分两阶段: stage 1 在 discarded off-task trajectories + autonomous robot play 上用 self-supervised Inverse Dynamics 学习 transferable motor priors; stage 2 用 minimal expert data 通过轻量 head 把 priors 接地到 language. 核心是用 task-agnostic 数据突破 expert demonstration scarcity.
⚙️ 方法：两阶段: (1) Inverse Dynamics 自监督学 motor priors (off-task + robot play 廉价数据); (2) 轻量语言对齐 head 用 minimal expert 数据把 priors 接地.
⚖️ 取舍：两阶段 pipeline 增加训练复杂度. Inverse Dynamics 学到的 motor priors 对新任务可能仍需微调.
📊 效果：SIMPLER benchmark 上匹配 1M expert trajectories 训练水平, 比 standard BC 高 10%. 摄像头扰动下保留 25% 成功率 (baseline 归零).
🏢 团队：Junhao Shi, Siyin Wang, Xiaopeng Yu, Li Ji, Jingjing Gong, Xipeng Qiu → Fudan University; Shanghai Innovation Institute

Discrete Diffusion Language Models for Interactive Radiology Report Drafting

放射科医生写报告通常是「一边看片子一边打字」 — 先写「左肺下叶有阴影」, 然后回去再补「考虑炎症可能」。传统的自回归 (AR) 模型是「从左往右」一个字一个字写, 你想回头补一句话就很难。离散扩散语言模型 (Discrete Diffusion LM, 比如 DiffusionGemma-26B) 则是「从一堆乱码反复擦改」 — 整张报告一次同时改好, 哪里要补都能补。这是第一个真正用 diffusion LM 做医学影像 + 报告草稿交互生成的研究。结果是: 在医学 VQA 上跟 AR 打平甚至超一点, 解码速度快 3.5-4 倍, 而且支持「医生写一段 → AI 在中间填充」的交互草稿工作流 (AR 根本做不到这一点)。

📖 专业版问题讲解 (展开)
用 mixture-of-experts discrete diffusion language model (DiffusionGemma-26B LoRA) 对比同尺寸 AR baseline (Gemma-4-26B) 在 medical visual question answering 上的表现. 通过 verbosity-robust LLM judge 评测, diffusion 在所有测试上 match 或 exceed AR. 解码速度快 3.5-4×, 核心亮点是 bidirectional denoising 带来的 drafting capability (在已有片段间填充), 这是 AR 不具备的能力.
⚙️ 方法：Mixture-of-experts discrete diffusion LM (DiffusionGemma-26B) + LoRA 微调. Bidirectional denoising canvas, 对比同尺寸 AR baseline (Gemma-4-26B).
⚖️ 取舍：Diffusion LM 训练成本高于 AR. Drafting capability 在长报告上比短文本更有价值.
📊 效果：Medical VQA 上 match 或 exceed AR, 解码快 3.5-4×. 支持 drafting (在已有片段间填充) 是 AR 做不到的能力.
🏢 团队：Max Van Puyvelde, H. Ibrahim Gulluk, Wim Van Criekinge, Olivier Gevaert → Stanford University School of Medicine (Biomedical Data Science); Ghent University (Mathematical Modelling, Statistics & Bioinformatics); Stanford University (Electrical Engineering)

WARP: Weight-Space Analysis for Recovering Training Data Portfolios

Foundation model 现在是「模型公开, 数据配方保密」 — 你能下载 Llama 的权重, 但不知道它训练时 web / code / 论文各占多少比例。这个 access asymmetry 很麻烦: 微调别人模型的人不知道原始分布, 容易「灾难性漂移」。WARP 想做的事: 只用公开的模型权重, 反推出训练数据的「比例指纹」。做法是把 base 模型和 fine-tuned 模型的权重差当成「影子」, 用 model merging 生成 pseudo-checkpoint 模拟「如果当时训练数据配比是这样的会留下什么足迹」, 然后从 weight space 的几何特征反推真实比例。在 BERT 和 GPT-2 上, 还原比例的平均误差只有 0.046-0.104, 比「成员推断」和「已知训练轨迹」两种方法都准。

📖 专业版问题讲解 (展开)
WARP 是一个只用 fine-tuned model weights (无需原始训练数据 / 训练轨迹) 反推训练数据 domain mixture 的框架. 核心思路是用 model merging 在 base + fine-tuned 之间生成 pseudo-checkpoints, 模拟不同 mixture 下的 weight-space 几何 footprint, 然后通过 parameter-free softmax readout 或 MLP projector 训练 geometric features → domain proportions. 在 BERT + GPT-2 controlled experiments 上, 平均 MAE 0.046-0.104, 优于 membership inference 和已知训练轨迹变体.
⚙️ 方法：Model merging 生成 pseudo-checkpoints → 提取 weight-space geometric features → parameter-free softmax readout 或 MLP projector 映射到 domain proportions.
⚖️ 取舍：依赖 model merging 的假设 (footprint 可线性近似). 仅在受控 mixture 比例下验证, 极端不平衡 (99%/1%) 可能失效.
📊 效果：BERT 上平均 MAE 0.046, GPT-2 上 0.104. 优于 membership inference attack 和已知训练轨迹的 baseline.
🏢 团队：Tzu-Heng Huang, Aditya Goyal, John Cooper, Frederic Sala → University of Wisconsin-Madison (ICML 2026 Workshop on Weight-Space Symmetries: from Foundations to Practical Applications)
