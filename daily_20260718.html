OpenAI CFO 发布 AI 时代计分卡：企业该看“每美元有效智能”，不是 Token 单价

OpenAI CFO Sarah Friar 7 月 17 日提出企业 AI 投资的新计分卡：不再只看席位数、活跃用户或单 Token 价格，而要衡量每美元产生多少可用工作。她把指标拆成四问：AI 完成了多少真正有价值的任务、每个成功任务的全成本是多少、结果是否足够可靠、规模扩大后单位投入能否买到更多工作。文章特别强调，便宜模型若需要多轮重试和大量人工复核，最终可能比昂贵但一次做对的模型更贵。

💡 这不是普通的财务科普，而是 OpenAI 在替企业采购重新定义 ROI 口径：竞争单位从“模型和 Token”转向“成功任务”。一旦 CFO 接受该框架，模型厂商会被迫同时交代完成率、重试次数、人工复核和失败成本，单纯降价不再等于更具性价比。更深一层，OpenAI 正把定价权锚到业务结果而非算力成本，为后续按任务、按 Agent 产出或按节省工时收费铺路；企业 AI 预算也会从创新试验逐步转为可审计的生产投入。

Boogu-Image-0.1: Boosting Open-Source Unified Multimodal Understanding and Generation

Boogu-Image-0.1 是开源统一多模态理解与生成模型家族，包含 Base / Turbo / Edit / Edit-Turbo 四个变体，覆盖高质量文生图、快速推理、指令编辑和中英双语文字渲染。论文证明针对性改进理解模块、数据质量和训练管线，配合 agentic inference-time scaling，能在极受限算力预算下逼近闭源 Nano-Banana-Pro 和 GPT-Image-2 的表现。

📖 专业版问题讲解 (展开)
We introduce Boogu-Image-0.1, an open-source unified multimodal understanding and generation model family comprising Base, Turbo, Edit, and Edit-Turbo variants. Closed-source multimodal systems like Nano-Banana-Pro and GPT-Image-2 achieve strong performance through system-level integration rather than a single model. We show that targeted improvements in model understanding, data quality, and training pipelines, coupled with agentic inference-time scaling, can substantially enhance generation and editing performance even under highly constrained compute budgets. Notably, this is accomplished with only 208.62 million unique images, and the base model's theoretical training cost is approximately $400K. We release weights, code, and recipes under Apache 2.0.
⚙️ 方法：Decoupled compute-efficient 范式：32B VLM 作为 Instruction Reasoner 负责复杂逻辑理解，8B 轻量 VLM 作为 Instruction Encoder 抽取 hidden state 作 DiT 条件信号；Boogu Arena 评测体系 + Qwen-Image benchmark + LongText benchmark 三个独立 benchmark 验证；Boosted Orthogonal Guidance 控制生成与理解的解耦；inference-time agentic scaling 通过 task-aware router 在 Base / Turbo / Pro / Turbo-Thinking 四个变体之间动态调度。
⚖️ 取舍：208.62M 图数据集规模限制了模型对长尾风格和细节场景的覆盖；agentic inference-time scaling 提升质量但显著增加单次推理时延，对实时应用是负担；8B VLM Encoder 可能丢失部分复杂 prompt 的语义细节，需要 router 在 Turbo-Thinking 模式下补偿。
📊 效果：在 Boogu Arena 上 ELO 分数：Boogu-Image-0.1-Turbo-Thinking 达到 1048，超过 Qwen-Image-2.0 (988) 和 Z-Image-Turbo (960)，逼近 GPT-Image-2 (1196) 和 Nano-Banana-Pro (1087)；训练仅用 208.62M 张图，base 模型理论训练成本约 $400K，明显低于同档闭源模型；全套开源（Apache 2.0），社区可复现。

VideoChat3: Fully Open Video MLLM for Efficient and Generalist Video Understanding

VideoChat3 是 4B 参数的全开源视频 MLLM，单一模型同时在通用、长视频、流式感知三类 benchmark 上超越同规模或更大规模开源模型。配套发布三个自建数据集：VideoChat3-Academic2M（通用）、VideoChat3-LV116K（长视频）、VideoChat3-OL617K（流式），覆盖从学术剪辑到真实长视频与在线交互的全谱系。

📖 专业版问题讲解 (展开)
Recent advances in video understanding have spanned motion, long video, and streaming interaction, driving this field toward real-world applications. Current open-source models remain limited to specific domains and incur high computational demands. We present VideoChat3, a fully open video MLLM that achieves strong performance with only 4B parameters, surpassing prior open-source models with equal or larger parameter counts across general, long-form, and streaming video benchmarks. We release three constructed datasets: VideoChat3-Academic2M, VideoChat3-LV116K, and VideoChat3-OL617K, together with the I3D-ViT backbone and an adaptive frame resolution module for streaming perception.
⚙️ 方法：I3D-ViT 时空表征：把 3D 卷积的 inductive bias 与 ViT 的长程注意力结合；Adaptive Frame Resolution for Streaming Video Perception：在 streaming 场景下动态调整帧分辨率以降低 token 开销；Academic2M 覆盖通用 video QA、LV116K 覆盖长视频、OL617K 覆盖在线流式；4B 参数在统一模型中同时通过三类 benchmark 评估。
⚖️ 取舍：4B 模型容量上限受限，复杂推理和细粒度动作识别仍落后闭源专用模型；三个数据集虽然覆盖范围广，但仍以学术语料主导的真实视频分布为主，长尾场景（如工业巡检/医疗内镜）泛化未验证；I3D-ViT 在极端长视频下是否能保持训练和推理效率，论文未给极限数据。
📊 效果：仅 4B 参数 VideoChat3 在通用 video QA、长视频、流式感知三类任务上均超过同/更大规模开源模型；三个数据集 Academic2M / LV116K / OL617K 形成连续覆盖；I3D-ViT 在保持精度同时显著降低 inference FLOPs；不依赖闭源数据，完全开源。

LongStraw: Long-Context RL Beyond 2M Tokens under a Fixed GPU Budget

LongStraw 通过 Architecture-aware execution 把 grouped RL 后训练推到 2.1M tokens 位置，固定 GPU 预算不增长。核心思路：shared prompt 不走 autograd，只保留后续 token 所需的 model-specific state；短 response branch 逐一 replay；用 GRPO 实例化。在 8 张 H20 上跑通 Qwen3.6-27B 至 2.1M positions，group size 8 比 group size 2 仅多 0.21 GB 显存。

📖 专业版问题讲解 (展开)
A growing gap separates inference context lengths from RL post-training: inference systems approach million-token contexts while post-training workloads remain at 256K tokens or below. We introduce LongStraw, an architecture-aware execution stack that fixes this gap without growing the GPU budget. Shared prompts bypass autograd, only model-specific state needed for subsequent tokens is materialized, and short response branches are replayed one at a time. The stack is instantiated with GRPO and run on Qwen3.6-27B and compressed-attention MoE GLM-5.2. On eight H20 GPUs, the implementation reaches 2.1M positions for groups of 2 and 8; increasing the group size adds only 0.21 GB of peak allocated memory. A separate stress test reaches 4.46M positions. On 32 H20 GPUs, the implementation carries a 2.1M-token prompt across all 78 layers of GLM-5.2 end-to-end.
⚙️ 方法：Architecture-aware execution stack：(1) shared prompt 不经过 autograd，节省显存；(2) 仅物化后续 token 必需的 model-specific state（如 KV cache 复用）；(3) 短 response branch 逐一 replay，避免整段 response 同时驻留显存。用 GRPO 实例化，同时支持 dense Qwen3.6-27B 和 MoE GLM-5.2，在 H20 集群上验证。
⚖️ 取舍：Replay 策略用时间换显存，总训练时长显著拉长；captured prompt state 是 detached 的，加上部分分布式 forward + gradient composition 路径未完成，论文明确指出'建立执行能力而非完整训练正确性'；不适合需要严格可微的全链路训练场景。
📊 效果：8 张 H20 上 Qwen3.6-27B 完成 grouped 评分和 response backward 至 2.1M positions（group size 2 和 8）；group size 增加仅多耗 0.21 GB peak allocated memory；压力测试至 4.46M positions；32 张 H20 上 GLM-5.2 全部 78 层端到端 2.1M-token 路径走通；建立 million-token RL 的 execution capacity。

Ring-Zero: Scaling Zero RL to a Trillion Parameters for Emergent Reasoning

Ring-Zero 把 zero RL 推到 1T 参数规模（Ring-2.5-1T-Zero），首次系统报告'苦涩教训'在 RL 上的复现：更大模型带来更高 sample efficiency 和表现上限。训练管线包括 clipped importance sampling + training-inference ratio correction + mixed-precision control 三大稳定化手段。模型自发涌现 anthropomorphism / self-verification / parallel reasoning / context anxiety 等高级认知行为。

📖 专业版问题讲解 (展开)
Zero RL has emerged as a powerful paradigm for eliciting chain-of-thought reasoning, but existing studies are largely restricted to small models. We present Ring-Zero, the first zero RL scaling to 1T parameters (Ring-2.5-1T-Zero). We show that scaling to 1T parameters significantly enhances sample efficiency and performance ceilings. The training process progresses sequentially through an initial discovery phase followed by a sharpening phase. The model spontaneously develops advanced cognitive behaviors, including anthropomorphism, structured formatting, self-verification, parallel reasoning, and context anxiety. We propose a three-dimensional evaluation framework for CoT quality (comprehensibility, reproducibility, efficiency).
⚙️ 方法：Ring-2.5-1T-Zero 是 1T 参数 MoE（63B 激活）+ Ring-2.5-flash-Zero 是 104B MoE（7.4B 激活）。训练管线三阶段 RL：First Stage RL（token-level loss + KL 约束）→ Self-Distillation → Second Stage RL（sample-level loss）→ Third Stage RL（按难度 Low/Medium/High 自适应推理深度）。关键 trick：clipped importance sampling ϵhigh=5.0 + training-inference ratio correction + mixed-precision control。Reward 由 accuracy component 和 format component 组成，later stages 用 LLM-as-a-Judge (Qwen3-Next-80B-A3B-Instruct) 替代 rule-based 验证。训练在 320×H200 上跑，Megatron 训练引擎 + SGLang rollout 引擎 + Areal RL 框架调度。评估在 7 个数学 benchmark（AIME 2024-2026 + HMMT Feb/Nov 2025-2026 + IMOAnswerBench）做 pass@1。
⚖️ 取舍：1T zero RL 训练基础设施与算力门槛极高，小团队或独立实验室几乎无法复现；naive scaling 暴露 poor readability / token redundancy / 缺自适应推理深度，作者靠 clipped IS + ratio correction + mixed-precision 三大工程 trick 压住，但每多一个组件都增加调参面；emergent cognitive behaviors 虽是亮点也意味着能力不可精细控制，生产部署的 safety 风险显著上升。
📊 效果：First Stage RL 已在 AIME 2026 达 84.2%（无任何人类标注）；Second Stage RL + Yarn=2 让 Ring-2.5-1T-Zero 在 7 个 benchmark 全部逼近 GPT-5.5 / Claude Opus 4.8 / Gemini 3.1 Pro；第三阶段 RL 的 High 模式（128k 预算）平均 IT 20817 tokens，Low 模式（4k 预算）平均 IT 2353 tokens；emergent cognitive behaviors 在 1T 模型上明显但在小模型上不出现。

SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning

SEED 通过 policy-as-analyzer 把已完成的 on-policy 轨迹转成 hindsight skill，再以 skill-induced probability shift 作 dense token-level on-policy distillation signal，与 outcome-based RL 联合优化。两个阶段：Stage 1 Hindsight Skill SFT 让 policy 学会从轨迹抽取自然语言 skills；Stage 2 Self-Evolving On-Policy Distillation 用同一 policy 同时做 actor 和 analyzer，组成自演化环。

📖 专业版问题讲解 (展开)
Outcome-based RL provides sparse, trajectory-level rewards that offer limited guidance on intermediate decisions, leaving a supervision gap between episode-level outcomes and token-level policy learning. We propose SEED (SElf-Evolving On-Policy Distillation), which converts completed on-policy trajectories into hindsight skills and distills their behavioral effect back into the policy model through a self-evolving training loop. The same policy model serves both as rollout actor and trajectory analyzer, extracting natural-language skills describing reusable workflows, decisive observations, or failure-avoidance rules. The resulting skill-induced log-probability shift over sampled actions forms a dense token-level distillation signal, jointly optimized with outcome-based RL.
⚙️ 方法：Stage 1 Hindsight Skill SFT：在离线轨迹上训练 policy 抽取可复用 workflows / 失败避免规则的 natural-language skills；Stage 2 Self-Evolving On-Policy Distillation：policy 同时做 actor（采集轨迹）和 analyzer（抽取 hindsight skills），训练时对 sampled actions 在 ordinary context 和 skill-augmented context 下 re-score，把 probability shift 作为 dense token-level OPD signal。Self-evolving loop 让 supervision 始终与 policy 的当前能力对齐。
⚖️ 取舍：用'分析自己轨迹'换密集监督信号，对策略容量与上下文长度提出额外要求，policy 必须兼具执行 + 复盘能力；hindsight skills 质量受 policy 当前能力上限约束（鸡生蛋问题），冷启动期效果可能有限；额外 re-score 步骤拉长训练时间，对大规模 agentic rollout 的吞吐是负担。
📊 效果：在 embodied interaction / web navigation / search-based QA / visual perception and planning 四类 agentic benchmark 上验证：SEED 持续优于 GRPO、Skill-GRPO、OPSD、Skill-SD、RLSD、SDAR 等 baseline；ALFWorld 平均 91.8 vs GRPO 75.0；Search-based QA 平均 45.7 vs GRPO 36.1；WebShop 成功率 78.9 vs GRPO 44.6；sample efficiency 改善明显。
