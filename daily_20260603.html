MCP-Persona: Benchmarking LLM Agents on Real-World Personal Applications via Environment Simulation

现有 MCP 智能体评测基准只看通用信息检索工具,完全没覆盖真实个人/社交类应用(账户/本地数据库),无法反映工具在个性化场景下的失效问题。

⚙️ 方法：提出 MCP-Persona 基准:用环境模拟器把 Reddit、小红书、Lark/飞书、Slack 等真实个人应用封装成 MCP 工具集,集中评估智能体在带身份/带状态工具上的表现。
📦 代价：未明确给出训练成本;作为评测基准,核心开销是 5+ 类 MCP 应用的工具环境构建与多 SOTA 智能体(闭源+开源)的大规模推理跑分。
📊 效果：多款 SOTA 智能体在 MCP-Persona 的个性化工具上均出现明显能力塌陷,基准作为"诊断器"有效暴露了通用 Agent 在账户/本地数据场景下的短板。
🏢 团队：上海交通大学(王文豪/牛培芝等,通讯王延峰、陈思衡均在 SJTU);ICML 2026 Camera Ready。

From Layers to Submodules: Rethinking Granularity in Replacement-Based LLM Compression

现有 LLM 替换式压缩(剪掉整层+拟合残差)强制"整层粒度+连续层选取",把注意力/FFN 都同等处理,实际上预训练 Transformer 的冗余既不连续也不在两类子模块间均匀分布。

⚙️ 方法：提出 SubFit:在子模块(Attention/FFN)粒度上做非连续选取,并为每类子模块各自训练一个轻量拟合残差旁路,仅需少量校准数据即可后训练压缩。
📦 代价：在 10 个 LLM(5 base + 5 instruct)上跑 5 档稀疏度(12.5%–37.5%),覆盖 4 个 baseline;属于后训练方法,只需校准数据,未给出 GPU 小时数。
📊 效果：在所有稀疏度下均取得最优困惑度-精度权衡;25% 稀疏度时保留 84.6% 稠密下游精度,困惑度仅 2.42×,优于最强 baseline 的 81.6%/4.34×,并实测带来推理加速与 KV-cache 节省。
🏢 团队：意大利特伦托大学(University of Trento)Cunegatti/Vukojevic/Nielsen/Iacca 团队(Iacca 实验室);代码 github.com/eliacunegatti/SubFit。
arXiv:2606.02569 · 论文精读

AdaCodec: A Predictive Visual Code for Video MLLMs

Video MLLM 把每帧都当独立 RGB 图独立编码,视觉 token 大量重复相邻帧已编码过的物体/背景/布局,长视频场景下 token 与首 token 时延(TTFT)开销巨大。

⚙️ 方法：提出预测式视觉码 AdaCodec:仅当条件预测代价高时发送完整参考帧,否则用 P-token 编码运动+预测残差;在 Qwen3-VL-8B 上做按帧压缩路由。
📦 代价：在 11 个 benchmark 上跑 Qwen3-VL-8B;视觉 token 预算 32k vs baseline 224k(1/7),实现更快首 token(9.26s→1.62s),未单独披露训练 GPU 小时数。
📊 效果：在 1/7 视觉 token 预算下,32k AdaCodec 在所有长视频 benchmark 上超过 224k baseline;在 5 个通用视频 benchmark 上平均得分提升,TTFT 由 9.26s 降至 1.62s。
🏢 团队：上海交通大学(侯浩文/王佳祺等)+ 微软亚洲研究院 MSRA(段楠),核心团队来自 SJTU 未来技术学院/计算机系。

SafeSteer: Localized On-Policy Distillation for Efficient Safety Alignment

LLM 安全对齐普遍带来"对齐税":在通用能力上掉点;现有方法靠双目标折中+海量通用数据/奖励模型,代价高且对通用能力损伤仍大。

⚙️ 方法：SafeSteer 用 activation steering 构造一个安全教师,再设计安全 token 选择算法,只对安全 token 施加 on-policy 反向 KL 蒸馏,把改动局限在稀疏的安全特征上。
📦 代价：仅需 100 条有害样本 + 零通用数据,数据量不到前序 baseline 的 1%;在多种 LLM 上训练,未披露 GPU 小时数。
📊 效果：在 7 个安全 benchmark 上保安全、在 5 个通用 benchmark 上几乎不掉点,取得当前最优的 safety-vs-capability 权衡;已投稿 EMNLP 2026。
🏢 团队：北京交通大学(李昊、安敬坤等,通讯沙磊、姚金戈均在 BJTU 计算机学院),项目页 anjingkun.github.io/SafeSteer。

Learning When to Translate for Multilingual Reasoning

推理大模型在多语言任务上对非英语输入存在显著推理 gap,根因是语言理解失败;全量英译成本高、且模型本可直答时再翻译就是浪费。

⚙️ 方法：提出 Luar:用强化学习让 RLM 自己决定"直接答 vs 先英译再答",只在翻译辅助推理明显胜出的样本上触发翻译,避免无谓翻译。
📦 代价：在多语言推理 benchmark 上做 RL 训练(类 GRPO 框架),相对逐题全量翻译显著降低翻译调用次数,具体 GPU 小时数未明确给出。
📊 效果：在多语言推理基准上优于标准 GRPO 与其他训练 baseline,低资源语言提升尤其明显;翻译行为可泛化到训练中未见过的低资源语言。
🏢 团队：韩国浦项工科大学 POSTECH(姜德赫/金贤勋/李根培,Lee 实验室,CS 系),代码 github.com/deokhk/LUAR。
