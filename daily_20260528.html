Algorithmic Monocultures in Hiring

🎯 问题：当多数企业使用同几家算法供应商的招聘筛选算法时，同一求职者群体反复被拒聘，导致种族和个体层面的结果同质化问题。
⚙️ 方法：获取并分析同一算法供应商筛选的300万求职者、400万份申请数据集，利用招聘算法的确定性可复现性生成求职者若投递所有职位的反事实结果，从而量化算法单一文化对不同种族群体的影响。具体通过构建反事实实验：给定同一求职者特征，分别模拟投递该供应商服务的所有雇主职位，追踪哪些职位会返回拒聘结果。
📦 代价：300万名求职者、400万份申请，由同一算法供应商提供筛选，数据涵盖亚裔和非裔美国人申请者。
📊 效果：亚裔申请者中有14.74%的申请、非裔申请者中有25.87%的申请投递到对其产生不利影响的职位；申请10个职位的求职者中有4%被全部推荐拒聘。
🏢 Rishi Bommasani (Stanford), Sarah H. Bana, Kathleen A. Creel, Dan Jurafsky, Percy Liang (Stanford/Cornell)

MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation

🎯 问题：现有技能创建方法将技能视为孤立、静态的产物，限制了技能的可复用性、可靠性和长期改进能力。
⚙️ 方法：MUSE-Autoskill实现统一的技能生命周期管理：1）技能创建时提取可泛化的任务模式为可复用单元；2）技能级记忆机制以键值结构存储每个技能执行后的反馈和经验，检索时基于语义相似度而非精确匹配；3）通过单元测试验证技能正确性，运行时收集执行失败样本触发技能自动 refinement；4）技能评估器计算每个技能的任务覆盖率、成功率和质量得分，用于指导新任务分配。
📦 代价：在SkillsBench基准上进行评估，使用技能级记忆机制积累跨任务经验。
📊 效果：论文未给出具体量化结果，仅报告技能生命周期管理可提升任务成功率、效率、复用率和跨智能体迁移能力。
🏢 Huawei Lin, Peng Li, Jie Song, Fuxin Jiang, Tieying Zhang

LocateAnything: Fast and High-Quality Vision-Language Grounding with Parallel Box Decoding

🎯 问题：视觉-语言模型将视觉定位任务表述为坐标token生成问题，将2D边界框串化成多个独立学习的1D token进行解码，这种逐token解码与边界框的几何耦合结构不匹配，且严格串行生成造成推理瓶颈。
⚙️ 方法：并行边界框解码（PBD）：将边界框的(x1,y1,x2,y2)四个坐标和点坐标作为原子解码单元，在单一步骤中同时解码整个边界框而非逐token串行生成；通过几何一致性注意力机制确保框内坐标的语义一致性；开发可扩展数据引擎利用自动化标注工具整理超过1.38亿训练样本的LocateAnything-Data大规模数据集，涵盖高精度定位的多样化数据。
📦 代价：LocateAnything-Data数据集包含超过1.38亿训练样本，覆盖高精度定位的多样化数据。
📊 效果：论文未给出具体的吞吐量提升倍数或IoU精度数值，仅泛泛称在多个基准测试中实现显著更高的解码吞吐量，同时提升高IoU定位质量。
🏢 Shihao Wang, Shilong Liu, Yuanguo Kuang, Xinyu Wei, Yangzhou Liu, Zhiqi Li, Yunze Man, Guo Chen, Andrew Tao, Guilin Liu, Jan Kautz, Lei Zhang, Zhiding Yu (NVIDIA)

Natural Language Query to Configuration for Retrieval Agents (BRANE)

🎯 问题：现代检索智能体涉及众多配置选择（LLM、检索器、文档数量、跳数、合成策略），但通常在 workload 层面手动调优一次，导致每个查询的优化空间未被充分利用。
⚙️ 方法：BRANE使用LLM将每个自然语言查询转换为 workload 特定特征向量（包含查询复杂度、领域、预期答案类型等），然后训练轻量级每配置预测器（基于梯度提升决策树）对每个候选配置进行成功率预测；推理时贪心选择预测正确率最高的配置，若存在多个预测正确率相近的配置则选择成本惩罚最小的配置，无需重新训练即可实现可调的成本-质量权衡。
📦 代价：在MuSiQue、BrowseComp-Plus和FinanceBench三个基准上评估。
📊 效果：BRANE以最高89%更低的成本达到与最佳固定配置相同的准确率，优于LLM路由、基于规则和微调Qwen3-4B基线；在MuSiQue上以22美元成本达到84.3%准确率，而最佳固定配置需要185美元。
🏢 Melissa Z. Pan, Negar Arabzadeh, Mathew Jacob, Fiodar Kazhamiaka, Esha Choukse, Matei Zaharia (Stanford)

GENESIS: Harnessing AI Agents for Autonomous 6G RAN Synthesis, Research, and Testing

🎯 问题：蜂窝无线接入网络（RAN）的研发受制于六个结构性流程——从标准规范合成代码、互操作性测试、稳定性加固、数据驱动优化到新波形发现和安全加固——每个流程每次迭代都耗费数月人工工程工作。
⚙️ 方法：GENESIS框架基于三个可组合原语（智能体负责决策、技能封装可执行单元、钩子处理环境交互）和知识层SYNAPSE（作为真值来源和所有产物的接收方），将意图（规范条款、遥测异常、研究假设）通过意图解析智能体转换为具体任务，由技能库调用对应工具执行，执行结果经钩子反馈到SYNAPSE知识层进行持久化，知识层支持增量更新和跨任务检索，使能力随运行次数复利增长。
📦 代价：在真实硬件上进行OTA实验验证，而非仅依赖仿真。
📊 效果：论文未给出具体量化结果，仅描述该框架在真实硬件OTA实验中验证有效，能自动化完成RAN研发六大结构性流程。
🏢 Tamerlan Aghayev, Maxime Elkael, Michele Polese, Minh Dat Nguyen, Gabriele Gemmi, Andrea Lacava, Ali Saeizadeh, Reshma Prasad, Paolo Testolina, Angelo Feraudo, Soumendra Nanda, Pedram Johari, Salvatore D'Oro, Tommaso Melodia
