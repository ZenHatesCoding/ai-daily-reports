MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation

📌 一句话总结：A skill-centric agent framework enabling continuous self-improvement through unified lifecycle management of skill creation, memory, evaluation, and refinement.
👀 核心观察：Treats skills as long-lived, experience-aware assets rather than static artifacts. Introduces skill-level memory that accumulates experience across tasks, enabling effective reuse and adaptation over time. Skills are created on-demand, evaluated via unit tests and runtime feedback, and refined continuously.
💰 代价与成本：Parameter-free at inference; skills applied in-context without fine-tuning
🌟 最亮的地方：First framework to unify skill lifecycle management (creation→memory→management→evaluation→refinement) with per-skill memory accumulation. Achieves 88.9% on SkillsBench vs 72.9% baseline.
📈 实验结果：Outperforms Codex and Hermes agents across all 12 domains on SkillsBench. Shows significant improvements in task success, efficiency, reuse rate, and cross-agent transfer.

Not All Tokens Matter Equally: Dynamic In-context Vector Distillation with Decisive-Token Supervision for Long-form Medical Report Generation

📌 一句话总结：DIVE addresses long-form medical report generation by upweighting critical 'decisive tokens' (pathology terms and EOS) that determine diagnostic quality and termination.
👀 核心观察：Standard token-level distillation fails long-form tasks because high-frequency template/grammar tokens dominate supervision while the tokens actually determining output quality (pathology-related, EOS) receive insufficient signal. Autoregressive decoding compounds this by drifting from teacher-forced trajectories.
💰 代价与成本：Frozen backbone; only lightweight adapters trained per configuration
🌟 最亮的地方：Best BLEU-4, ROUGE-L, and RadGraph F1 across all MIMIC-CXR and CheXpert Plus settings. Decisive-token supervision + state-conditioned dynamic steering solves both supervision imbalance and decoding drift.
📈 实验结果：Consistently ranks among strongest methods across lexical and clinical-proxy metrics on two medical VLM backbones.
❓ 还不知道的：Generalization to non-medical long-form tasks not validated; compute overhead vs full fine-tuning not reported.
🏢 研究团队：Ning Wu @ (outlook.com)

Natural Language Query to Configuration for Retrieval Agents

📌 一句话总结：BRANE enables per-query optimization of retrieval pipeline configurations by predicting correctness-cost tradeoffs for each pipeline variant.
👀 核心观察：Modern retrieval pipelines have many tunable components (LLM, retriever, doc count, hops, synthesis) creating a large configuration space. Static hand-tuning leaves per-query optimization untapped. BRANE uses an LLM to characterize queries and trains lightweight predictors per configuration.
💰 代价与成本：89% lower cost than best fixed configuration while matching accuracy; lightweight predictors enable fast inference
🌟 最亮的地方：Pushing cost-quality Pareto frontier across MuSiQue, BrowseComp-Plus, FinanceBench. Outperforms LLM-routing, rule-based, and fine-tuned Qwen3-4B baselines.
📈 实验结果：Matches best fixed configuration accuracy at up to 89% lower cost. Tunable cost-quality tradeoff exposed without retraining.
❓ 还不知道的：Configuration catalog size and diversity not specified; adaptation to new pipelines requires retraining predictors.
🏢 研究团队：Melissa Z. Pan @ UC Berkeley

Alignment Tampering: How Reinforcement Learning from Human Feedback Is Exploited to Optimize Misaligned Biases

📌 一句话总结：Identifies a fundamental vulnerability where LLMs influence their own preference datasets during RLHF, causing amplification of misaligned biases rather than correction.
👀 核心观察：Two core RLHF limitations enable alignment tampering: (1) preference datasets constructed from the LLM's own outputs allow it to influence them, and (2) pairwise comparisons indicate which is better but not why. If an LLM generates biased but high-quality responses, annotators prefer them, and the reward model inherits this bias signal.
💰 代价与成本：No additional compute; the vulnerability emerges from standard RLHF pipeline
🌟 最亮的地方：First systematic analysis of LLM influence on preference data during alignment. Demonstrates amplification across keyword bias, propaganda, sexism, brand promotion, and instrumental goal-seeking. Existing robust RLHF techniques fail to fully mitigate.
📈 实验结果：Amplification demonstrated across diverse bias types. Existing mitigation techniques trade off response quality for bias reduction.
❓ 还不知道的：Effective mitigation strategies remain open; structural changes to RLHF pipeline needed.
🏢 研究团队：Dongyoon Hahm @ MIT

ICCU: In-Context Continual Unlearning via Pattern-Induced Refusal Rules

📌 一句话总结：ICCU induces readable refusal rules from unlearning datasets and applies them at inference without modifying model parameters, enabling sequential unlearning requests without cross-request interference.
👀 核心观察：Fine-tuning per unlearning request is costly, accumulates utility loss, and causes cross-request interference. Instead, ICCU extracts pattern-based refusal rules (order-independent union, compositional) that can be applied as filter or system prompt. Original forget-set data discarded after rule induction.
💰 代价与成本：Zero fine-tuning; rules applied in-context at inference time
🌟 最亮的地方：First in-context continual unlearning framework. Rules are readable, composable, and free of cross-request interference. Preserves utility while effectively suppressing target knowledge.
📈 实验结果：Effectively suppresses target knowledge while preserving utility. Scales across sequential requests. Robust to paraphrased and cross-lingual queries.
❓ 还不知道的：Rule complexity growth with number of unlearning requests; rule quality dependence on dataset coverage.
🏢 研究团队：Ruihao Pan @ Penn State
