Pushing the Limits of LLM Tool Calling via Experiential Knowledge Integration and Activation

2025-2026 LLM tool calling 框架在长视野 Agent 任务里频繁失败——工具调用的"经验知识"（哪个工具好用 / 哪个 API 易踩坑 / 哪个错误码常见）未结构化积累，每次新任务都要重新摸索。

⚙️ 方法：提出"Experiential Knowledge Integration"（经验知识集成）——从历史 Agent 执行轨迹中提炼工具调用经验知识（哪类工具适合哪类任务、哪些 prompt 模式有效），嵌入到 LLM 工具调用的激活层中；同时通过 Activation Steering 让模型在工具调用时主动检索相关经验。
⚖️ 取舍：经验知识库需要持续更新——新增工具 / API 变更时旧经验可能误导；Activation Steering 引入额外推理延迟，单次工具调用延迟比 baseline 高 15-25%。
📊 效果：在 ToolBench + 真实企业 API benchmark 上比 ReAct / Toolformer 提升 22% 工具调用成功率；新型未见过的工具上泛化能力提升 18%。
🏢 团队：Microsoft Research + Peking University 联合团队，第一作者 Wei Liu，通讯作者 Yansong Feng（PKU）。

The Shibboleth Effect: Auditing the Cross-Lingual Distributional Skew of Large Language Models

LLM 在多语言任务上呈"英语霸权"——主流 benchmark 显示 GPT-4 / Claude 在非英语任务上准确率下降 20-40%，但根因不明：是训练数据分布偏英语，还是模型对低资源语种表征能力本身弱？

⚙️ 方法："Shibboleth Effect"提出跨语言分布偏差的审计方法——通过 controlled probing 检查 LLM 在不同语言下"语义等价输入"的表征是否真的一致；用 cross-lingual probing + causal intervention 定位表征偏差来源。
⚖️ 取舍：审计方法不能直接修复偏差——论文定位问题但未给完整修复方案；建议的"训练数据再平衡"成本极高（需重新训练 LLM）。
📊 效果：审计 12 个主流 LLM 跨语言偏差——平均 35% 的非英语 prompt 触发了英语"惯性"（即使语义上可以用本地语言完成）。Shibboleth 偏差与模型规模呈反比（越大越均衡），但绝对偏差仍显著。
🏢 团队：Stanford University + ETH Zurich 联合团队，第一作者 Anna Chen，通讯作者 Tatsunori Yamamoto（Stanford NLP Group）。

Modeling Complex Behaviors: Multi-Personality Composition and Dynamic Switching in Vision-Language Models

Vision-Language Models (VLM) 在"单角色一致行为"上表现好，但现实场景需要模型在不同上下文切换不同"人格 / 行为模式"（医生模式 vs 老师模式 vs 调试模式）。现有 VLM 切换是手工 prompt 工程，无法自动且持续。

⚙️ 方法：提出"Multi-Personality Composition and Dynamic Switching"——为 VLM 引入"personality slot"（人格槽），每个槽绑定一组行为参数；通过 dynamic router 根据当前输入上下文自动选择 / 混合多个 personality slot；训练数据用 GPT-4V 自动合成多角色对话对。
⚖️ 取舍：多个 personality slot 同时激活时 GPU 显存占用线性增长（4 个 slot → 4x 显存）；dynamic router 在 ambiguous 输入（不属于任何已知人格）上决策不确定，需要 fallback 策略。
📊 效果：在 multi-personality VLM benchmark 上比 baseline 提升 28% 行为一致性；在角色切换速度上 5x 快于手工 prompt 切换；用户研究显示"医生 + 老师"双角色 VLM 在医疗教育场景接受度 78%。
🏢 团队：Tsinghua University + Microsoft Research Asia 联合团队，第一作者 Zhihong Chen，通讯作者 Jie Zhou（Tsinghua）。

Beyond Uniform Token-Level Trust Region in LLM Reinforcement Learning

LLM RL（PPO / GRPO / DPO 等）的 trust region（信任域）约束通常在 token 级别——限制每个 token 概率变化幅度。但在长视野任务里，token 级信任域过松或过紧都会导致训练不稳定：过松策略崩溃，过紧学不到新行为。

⚙️ 方法：提出"非均匀 token 级信任域"——不同 token 位置用不同 trust region 阈值，关键 token（决定推理走向的逻辑词）紧约束，常见 token（停用词 / 标点）松约束；通过 learned critic 预测每个 token 的"重要性"。
⚖️ 取舍：Critic 预测 token 重要性本身是 overhead——训练时间比标准 PPO 增加 35%；不同任务的关键 token 集合不同，迁移到新任务时需要重新训练 critic。
📊 效果：在 math reasoning + code generation 两个 RL 任务上，比标准 PPO/GRPO 提升 18% 收敛速度 + 12% 最终性能；训练稳定性显著提升（reward 曲线方差减少 40%）。
🏢 团队：Tsinghua + Beijing Academy of AI (BAAI) 联合团队，第一作者 Jiawei Zhang，通讯作者 Yujia Qin（BAAI）。

Attention Amnesia in Hybrid LLMs: When CoT Fine-Tuning Breaks Long-Range Recall, and How to Fix It

Hybrid LLM（Transformer + 其他架构混合）在 CoT（Chain-of-Thought）微调后出现"Attention Amnesia"——长程推理能力退化，模型在中后段丢失对前文的注意力，导致 1000+ token 推理链条崩溃。

⚙️ 方法：诊断"Attention Amnesia"的根因——CoT 微调让模型"过度关注局部推理步骤"，训练目标让 short-range attention 增强但 long-range attention 衰减；提出 Long-Range Anchor Loss 作为正则项，强制模型在每个推理段保留对初始 query 的注意力。
⚖️ 取舍：Long-Range Anchor Loss 增加 20% 训练成本；论文承认这一方法对纯 Transformer 的 LLM 效果有限——主要解决 Hybrid 架构的特定问题。
📊 效果：在 long-form reasoning benchmark（数学竞赛 + 长文档 QA）上恢复 Hybrid LLM 长程推理能力到接近非微调 baseline；推理链条 1000+ token 准确率从 32% 提升到 71%。
🏢 团队：Stanford University + MIT CSAIL 联合团队，第一作者 Yifei Wang，通讯作者 Diyi Yang（Stanford NLP）。
