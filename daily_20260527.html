Algorithmic Monocultures in Hiring

📌 📌 一句话总结：利用包含300万申请者和400万份申请的数据集，分析同一算法供应商筛选系统中的种族差异，发现算法单一文化导致特定种族群体面临系统性拒绝。
👀 👀 核心观察：这是首次大规模实证研究算法单一文化（monoculture）对招聘筛选公平性的影响，揭示了当大多数雇主使用同一算法供应商时，同一种族群体可能遭受系统性的集体性歧视。
💰 💰 代价与成本：数据规模为300万申请者和400万份申请，属于大型数据集但未提及GPU算力或模型训练成本（可能不需要训练，主要为数据分析）。
🌟 🌟 最亮的地方：首次从算法供应商集中化角度研究歧视问题，提出了算法单一文化假说，而非关注单个算法的偏见，视角新颖且具有重要的政策含义。

📌 📌 一句话总结：提出MUSE-Autoskill框架，通过统一的技能生命周期（创建、记忆、管理、评估、精炼）让LLM代理自动创建、可复用和持续改进技能，解决现有方法中技能孤立静态的问题。
👀 👀 核心观察：这个研究最值得关注的一点是"技能级记忆"的设计——每个技能都能累积跨任务的经验记忆，这就像给每个工具都配了一个小笔记本，记录它用过多少次、成功失败原因，下次用时会根据这些经验调整策略，比以前要么忘得一干二净、要么记成一本乱账的方法聪明多了。

Natural Language Query to Configuration for Retrieval Agents

📌 📌 一句话总结：BRANE通过LLM提取查询特定特征并训练轻量级预测器，实现了对检索agent管道的按查询动态配置优化，在保证准确率的同时大幅降低推理成本。
👀 👀 核心观察：这篇论文发现了一个反直觉的事实——LLM只是众多配置选项之一，调整合成方法和检索器的效果比只调LLM大得多。而且不同查询的最优配置差异很大，所以按查询动态选配置比静态调优有很大空间。
💰 💰 代价与成本：文中提到仅分析600个查询×60个配置就花费约11,000美元。训练方面使用前沿LLM(如GPT-4)提取特征，用更便宜的LLM标记数据，训练轻量级预测器(每个Pareto配置一个)。
🌟 🌟 最亮的地方：提出用LLM自动生成工作负载特定的二元特征作为"翻译层"，连接原始查询语义和配置空间。这解决了通用特征(如need_joint_reasoning)无法区分同工作负载内查询的问题。而且推理时可随时调整准确率/成本目标而不需重训练。
