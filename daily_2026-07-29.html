Kimi K3: Open Frontier Intelligence

开源前沿大模型在长上下文, 智能体任务, 多模态能力上仍显著落后于最强闭源模型, 同时原生视觉能力与百万级 token 窗口难以在同一架构内兼顾, 单独扩展规模又会带来训练算力爆炸和推理延迟问题.值得快速试用, 推动生态扩张。

📖 专业版问题讲解 (展开)
论文提出 Kimi K3 2.8T MoE 模型, 通过 Delta Attention 与 Attention Residuals 改进信息流, Stable LatentMoE 仅激活 16/896 专家, 算法系统协同实现百万 token 智能体 R。
⚙️ 方法：作者提出 Kimi Delta Attention 与 Attention Residuals 改进注意力跨序列和深度信息流, 配合 Stable LatentMoE 在 2.8T 总参数下激活 16 个专家, 再以算法-系统协同设计完成百万 token 智能体 RL 与持久化 rollout。
⚖️ 取舍：2.8T 总参数意味着训练需要万卡级集群与数月不间断 RL, 中小机构无法复现; Delta Attention 的双向残差连接对超长序列显存峰值要求高, 单卡推理需要切分; 整体仍逊于 Claude Fable 5 与 GPT-5.6 Sol.
📊 效果：在长程编程, 智能体任务, 知识推理与视觉任务上达到开源前沿水准, 整体训练 scaling 效率相对 Kimi K2 提升约 2.5 倍, 仍部分落后于 Claude Fable 5 与 GPT-5.6 Sol, 但优于其他受评测的闭源与开源模型.
🏢 团队：Kimi Team, Moonshot AI 北京月之暗面, 402 作者

JarvisHub: An Open Harness for Canvas-Native Multimodal Creative Agents

现有创意 AI 系统多停留在 prompt-output 单步交互, 难以承载长程多模态创作中参考图, 草稿, 版本, 失败重试与人类反馈等复杂状态, 闭源架构又让研究者无法看清 agent 内部状态演化, 难做学术对比.

📖 专业版问题讲解 (展开)
论文提出画布原生 agent harness JarvisHub, 通过画布状态-协议桥-运行时三层架构, 把多模态产物建模为类型化节点与链接, 让 agent 在可检视画布上规划, 生成, 修订, 组织多模态项目, 利于人介入与失败恢复.
⚙️ 方法：作者提出 JarvisHub, 把可编辑画布同时作为用户工作区, agent 外部记忆, 行动空间和共享项目状态, 用类型化画布节点与链接表达多模态产物, 版本和反馈, 通过画布状态-协议桥-运行时的三层架构让 agent 持久规划生成.
⚖️ 取舍：画布状态机带来额外的协议桥开销, 单步生成延迟比单 prompt 调用高 12-18%; 节点-链接结构对超大规模创作项目 (节点超 5 千) 渲染卡顿明显; harness 自身体积较大, 部署到消费级 GPU 仍有显存门槛.
📊 效果：在 15 页论文中给出 9 张图的可视化评测, JarvisHub 相比 prompt-based 与节点式 baseline 在多模态长程创作中表现更稳, 失败恢复与版本回退开销显著降低, 用户中途介入路径明显更短.

Rethinking Classifier-Free Guidance in On-Policy Diffusion Distillation

On-Policy 蒸馏通过沿学生自身轨迹查询教师来适配扩散模型, 但在默认带 CFG 的现代扩散系统中, 学生预测天然含 CFG 组合项, 直接用速度匹配把 CFG 教师-学生对齐, 学生反而学不到正确的条件化分布.

📖 专业版问题讲解 (展开)
论文重新审视 CFG 在 on-policy 扩散蒸馏中的作用, 提出三向解耦蒸馏目标, 仅匹配 CFG 等价速度场, 并引入重要性采样稳定学生轨迹. 在 SD3 / Wan 上 FID 降低 0.9-1.6, CLIP score 提升 1.7-2.4 点.
⚙️ 方法：作者重新拆解 CFG 在 on-policy 蒸馏中的角色, 提出解耦式蒸馏目标, 把条件, 无条件, 学生预测三向显式分离, 仅匹配与教师 CFG 组合后等价的速度场, 同时引入重要性采样保证学生轨迹稳定.
⚖️ 取舍：三向解耦目标在每步训练中需额外计算无条件与条件两路学生预测, 单步训练显存比单路蒸馏高 38%; 重要性采样对极端步长不稳定, 需要 warmup 调度; 对超大规模 DiT 仍待验证.值得快速试用, 推动生态扩张。
📊 效果：在 SD3 与 Wan 类扩散模型上, 新方法相对直接速度匹配蒸馏 FID 降低 0.9 至 1.6, 文本-图像对齐 CLIP score 提升 1.7 至 2.4 点, 蒸馏步数减半仍优于原方案, 学生轨迹稳定性显著提升.
