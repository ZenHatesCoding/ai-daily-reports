arXiv:2606.05158 · 论文精读

Streaming Communication in Multi-Agent Reasoning

多智能体推理普遍'生成完整推理链再传递',端到端延迟随管线深度线性增长,生产级 Agent 部署被时延卡死;不改范式就只能牺牲推理步数或并发。

⚙️ 方法：StreamMA 把每个推理 step 一旦生成即流式下推给下游 Agent,管线并行相邻步骤,把 K 步串行延迟压成'1 步 + 流水线填充';推理质量不降反升(早步置信度天然高于晚步,提早暴露高置信信号可减少错误传播)。
⚖️ 取舍：流式管线让后步 Agent 必须接受'不完整上下文'做决策,调度复杂度↑;若前步预测错且已被下游消费,纠错成本比串行基线更高(rollback 链路更深、影响面更广)。
📊 效果：在多步推理 benchmark 上同时降低端到端延迟并提升最终准确率(具体倍数见正文表格),首个系统化把'流水线/流式'思想引入多智能体推理的工作。
🏢 团队：香港科技大学(HKUST)Ying-Cong Chen 团队,第一作者 Zhen Yang;面向多智能体推理的工程化加速。
arXiv:2606.05165 · 论文精读

STRIDE: Training Data Attribution via Sparse Recovery from Subset Perturbations

训练数据归因(TDA)是模型可解释/合规/数据治理刚需,但 LLM 规模下重训练(因果金标准)与全梯度追踪(近似法)都不可行,业界缺可用的 LLM 级归因工具。

⚙️ 方法：STRIDE 不算梯度,改为在'子集扰动'维度做稀疏恢复(Sparse Recovery):对多个小子集做扰动+观测输出变化,在扰动-影响矩阵上做 L1 稀疏回归识别关键训练样本,成本比 TRAK/Influence Functions 等梯度近似基线低一个数量级。
⚖️ 取舍：稀疏恢复依赖'少数样本确实主导预测'这一假设,LLM 普遍对大量样本做平滑利用,稀疏解可能不稳定,归因结果对扰动子集选择敏感;且只能给出样本重要性排序,无法解释'为什么这条样本关键'。
📊 效果：首次给出 LLM 级可扩展的因果近似 TDA,在精度与稳定性上优于 TRAK、Influence Functions 等梯度近似基线,成本远低于重训练(具体倍数见正文)。
🏢 团队：MPI-IS(马克斯·普朗克智能系统研究所)Bernhard Schölkopf 团队 + 多伦多大学 Zhijing Jin 合作,第一作者 Rishit Dagli;因果/稀疏恢复派系。
arXiv:2606.05161 · 论文精读

Beyond Text Following: Repairable Arbitration Reversals in Audio-Language Models

音频-语言模型(ALM)在文本与音频冲突时系统性偏向文本,业界分不清'音频信号没学到'还是'学到但被文本压制';不区分就无法对症修复,模态仲裁已成 ALM 落地最大瓶颈之一。

⚙️ 方法：提出 same-audio 反事实诊断:固定音频、移除冲突文本,测模型偏好是否反转;在 5 个 ALM + 4 个冲突任务上 64.1% 样本出现显著反转,证明音频答案在表征层是'在的',问题出在仲裁环节(repairable)。
⚖️ 取舍：反事实诊断只能区分'有没有学到',不指明'怎么修';移除文本后偏好反转证明表征存在,却没给出具体修复路径(改权重?改 prompt?改 token 优先级?),落地修复仍是开放问题。
📊 效果：首次系统化证明 ALM 音频-文本冲突下 64.1% 属仲裁反转(repairable)而非表征缺失,给出可复现的 same-audio 反事实诊断流程与 5 模型对比表。
🏢 团队：东北大学(中国)计算机学院 NLP 实验室,通讯作者 Shi Feng(石锋)/ Daling Wang(王大龙)/ Yifei Zhang(张逸飞),第一作者 Yichen Gao(高艺琛)。
arXiv:2606.05152 · 论文精读

Reinforcement Learning from Rich Feedback with Distributional DAgger

推理模型主流 RLVR 训练只给'对/错'一位奖励,执行轨迹、工具输出、专家修正、自评等富信号被全浪费,高难任务上单 bit 奖励方差极大、收敛慢,卡住了推理 RL 的进一步提效。

⚙️ 方法：把经典 DAgger 做'分布化扩展' Distributional DAgger:把专家/工具/自评等富反馈建模为分布奖励,代入 on-policy 模仿学习回路;在数学/代码/工具调用等任务上,样本效率与最终准确率优于 1-bit RLVR 基线(具体倍数见正文)。
⚖️ 取舍：富反馈管线每步要跑执行/调工具/自评,单步训练成本远高于 1-bit RLVR;且高度依赖反馈源质量——若专家或自评本身有偏,反向传播会把偏置放大,适用场景受限。
📊 效果：首次把'富反馈 RL'从论文级 demo 推到可训练框架,在数学/代码/工具调用等多步推理任务上以更少环境步达到比 1-bit RLVR 更高的最终准确率。
🏢 团队：作者 Rishabh Agrawal / Jacob Fein-Ashley / Paria Rashidinejad,具体机构与会议信息以 arXiv 正文披露为准。
arXiv:2606.05145 · 论文精读

Failed Reasoning Traces Tell You What Is Fixable (But Not by Reading Them)

后训练推理模型失败时,业界默认靠 test-time scaling 多 rollout 解决,但'失败 trace 里其实编码了修复路径';靠多采样是赌运气,该改测试时干预(prompt/工具/计划)却没改,算力被空转。

⚙️ 方法：提出'failed-trace recoverability'诊断:不读 trace 内容,只从其统计签名(长度/多样性/置信度曲线)区分'sampling 失败'与'structural 失败',为每类失败匹配不同测试时干预(更多 rollout vs. 改 prompt/工具/计划)。
⚖️ 取舍：诊断只判断'该改什么'不提供'怎么改'的最优解;落地到生产仍需人工或 Agent 闭环执行干预,且诊断本身要消耗一次推理开销,在极致低成本/低延迟场景不划算。
📊 效果：在多个推理 benchmark 上把失败 trace 分类后匹配干预策略,等算力下准确率比盲目多 rollout 显著提升;首次把'失败 trace 的统计签名'作为可干预信号系统化使用。
🏢 团队：Mila(蒙特利尔学习算法研究所) + 蒙特利尔大学,作者含 Irina Rish、Sarath Chandar、Eilif B. Muller 等;第一作者 Nizar Islah。
