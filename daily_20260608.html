Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads

LLM 智能体被部署到跨会话、跨小时的长期任务里，底层用来存/取/更新记忆的栈——扁平检索、LLM 抽提、事实压缩、智能体流控——业内缺乏系统级画像，架构师说不清成本、延迟、质量各从哪来。

⚙️ 方法：提出四轴系统分类法（写入/读取/组织/控制流）+"按阶段分账"的 profiling harness，把每条操作的成本分别归到构造、检索、生成三阶段；横向打 10 套代表性记忆系统 + 两套长程 benchmark 做对比基线，覆盖广度比前序系统论文（Mem0 / Awesome-Memory 等只测一两个栈）提升一个量级。
⚖️ 取舍：覆盖广把"诊断"侧拉满，但压死的是"处方"侧——给的是 10 条横切建议而非某个 silver bullet；写节奏、查询批量化、新鲜度 vs 延迟、跨实例共享之间的取舍随工作负载漂移，本质上是地图不是导航仪。
📊 效果：两套长程 benchmark 上首个 agent memory 系统级横评，附 10 条可执行建议；核心发现：读放大主犯常是去重/合并环节，而非向量检索本身。
🏢 团队：斯坦福大学 SystemX + KU Leuven，第一作者 Yasmine Omri，通讯 Tambe。

PC Layer: Polynomial Weight Preconditioning for Improving LLM Pre-Training

LLM 预训练对权重矩阵的"条件数"高度敏感——AdamW / Muon 这类二阶优化器一旦撞到谱分布不均的权重，迭代慢、收敛差；业内只能靠手动谱归一化或谨慎 init 反复救火。

⚙️ 方法：PC Layer——把低阶多项式预条件算子挂在每层权重上，主动压缩权重矩阵的奇异值谱，让它在训练全程落在有界区间；推理时可合并回主权重、零开销。相对"加 LayerNorm / spectral norm"基线，谱控制粒度更细、每步生效；相对"训练完再裁谱"流派，控制点提前到初始化后每次 step。Llama-1B + AdamW/Muon 双向验证。
⚖️ 取舍：谱控制把"稳定性/收敛速度"侧翘起来，但压死的是"理论适用范围"侧——只在深度线性网络上严格证明"有界 singular value ⇒ 几何收敛到全局最小"，非线性 Transformer 上的保证是经验性；多项式阶数本身也是新超参，跨架构需重搜。
📊 效果：Llama-1B 在 AdamW 与 Muon 两条路径上比标准 Transformer 更稳、收敛更快；理论侧对深度线性网络给出形式化证明。
🏢 团队：UIUC + 圣母大学，第一作者 Senmiao Wang，通讯 Ruoyu Sun / Alex Schwing。

USAD 2.0: Scaling Representation Distillation for Universal Audio Understanding

音频 LLM 需要一个通用编码器覆盖语音/声效/音乐三域，但 USAD、SPEAR 这类多域 SSL 编码器覆盖面窄；近一年研究又发现纯监督编码器反而和音频 LLM 对齐更好——两派结论打架。

⚙️ 方法：USAD 2.0 把 SSL 和监督基础模型的知识用 domain-aware 蒸馏统一到一个编码器里——先用多教师蒸馏吃下不同域信号，再加二阶段监督蒸馏对齐下游音频 LLM 任务，最后用深度扩展推到 1B 参数。相对 USAD 1.0 扩了音乐域、加了监督对齐；相对纯监督编码器又保留 SSL 通用性。
⚖️ 取舍：统一通用性翘起来了，但压死的是"教师冲突 / 训练复杂度"侧——多教师蒸馏时不同域标签空间会互踩，所以额外塞了 domain-aware 蒸馏头 + 二阶段监督，pipeline 阶段数明显变多，调参复杂度和训练成本一并抬高。
📊 效果：probing 与音频 LLM 评测两条线都达到强表现 / SOTA；1B 参数规模下首次把语音/声效/音乐三域装进同一编码器并对齐下游音频 LLM。
🏢 团队：MIT CSAIL 口语语言系统组，第一作者 Heng-Jui Chang，通讯 James Glass。

Reinforcement Learning Elicits Contextual Learning of Unseen Language Translation

LLM 翻译极低资源语言时，要么继续预训练（背特定语种、过拟合），要么"上下文里塞语法书"（同样过拟合）；一旦换语种，掉点严重——业内缺一种"会用工具、不死记具体语种"的元能力。

⚙️ 方法：用 outcome-based 强化学习 + 上下文里塞语言学笔记，对 chrF 这种纯表面奖励做策略优化——刻意不引入神经奖励模型。证明只需 chrF 这种表层指标，就能让模型学会"从给定上下文里抽取并应用语言学信息"，而不是记住某个具体语种。相对 SFT 基线（背语法书）泛化性来自 RL 探索性；相对纯 ICL 基线（裸塞提示），训练压力把"用上下文"的策略真正固化到权重里。
⚖️ 取舍：奖励极简把"易复现 / 不挑奖励模型"侧翘起来，但压死的是"奖励对齐质量"侧——chrF 只看字符级 n-gram 重合，碰到句法复杂、长程一致的译文打分偏弱；分析虽暗示配方可推广到其它"重上下文"任务，非翻译任务上的实证目前还没补齐。
📊 效果：在完全未见过的语种上，RL 训练过的模型比 ICL 与 SFT 基线都能更准地从上下文抽取并应用语言学信息，翻译质量明显更高。
🏢 团队：苏黎世大学计算机系，第一作者 Hanxu Hu，通讯 Rico Sennrich。

Latent Reasoning with Normalizing Flows

LLM 推理靠显式 CoT，每步必须先 verbalize 成 token 再走下一步；当中间更新是语义性的、不确定的、还没成形的，强制走离散串行 token 流就是带宽浪费。

⚙️ 方法：NF-CoT——用 normalizing flow（TARFlow 风格）在 LLM 主干里生成"连续思维位置"，和标准 LM head 的文本位置共用同一条因果流；保住了 KV-cache 解码、可估似然、直接策略梯度优化三件套。相对离散 CoT 基线潜在空间带宽更高、推理中间成本明显降低；相对先验潜在推理（如 Coconut），多保留一个 NF head 换兼容性。
⚖️ 取舍：潜在带宽 + 兼容性翘起来了，但压死的是"训练阶段架构复杂度"侧——NF head 与 LM head 同框让训练侧变得不规整；连续思维位置虽不影响解码时的 KV-cache，但 NF head 的容量 / 步数是新超参，并不是所有任务都立刻受用。
📊 效果：在代码生成 benchmark 上 pass rate 超过显式 CoT 与先验潜在推理基线；中间推理成本显著下降；支持在潜在空间直接做策略梯度优化。
🏢 团队：Apple MLR + 南京大学 + 字节 Seed；第一作者 Guancheng Tu，通讯 Jiatao Gu。
